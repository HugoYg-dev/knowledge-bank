# 实体：Pinecone

## 简介

**Pinecone** 是一款商业闭源的完全托管型（SaaS）向量数据库服务，专门面向大规模向量搜索场景设计。

## 核心特性

- **完全免运维**：无需管理集群、节点扩展与索引调优，用户仅需通过 API 进行读写与查询。
- **高可用与弹性扩容**：支持云端动态扩容，具备优异的延迟与召回性能。

## 选型考量

- **适用场景**：团队预算充足、不希望招募运维人员且数据合规允许使用海外公网 SaaS 服务的快速上线项目。
