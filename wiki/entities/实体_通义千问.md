# 实体：通义千问 / 千问AI平台

## 简介

**通义千问（Qwen）** 是阿里巴巴自主研发的通用大语言模型系列，于 2023 年发布。**千问AI平台** 为智能体工程化落地的核心承载基础设施，涵盖垂直领域 Agent 运行时、技能编排与多模型分工调度。

## 在阿里 RAG 中的应用

- Qwen 2.5 72B + Thoughts 功能在 RAR 相关性判断中表现最佳（错误召回率从 15.97% 降至 5.03%）；
- Qwen Max 在多样化图片引用处理上整体得分显著高于 Qwen 1.5 72B；
- 图片引用评估对比 Qwen 1.5 72B 和 Qwen Max。

## 智能体 Skill 工程体系实践（千问AI平台）

在 AI 投研平台等专业垂直场景中，千问团队沉淀了系统的生产级 Skill 构建范式：
- **三层套件架构（1 + 6 + 19）**：将传统平铺技能重构为 L1 规则基座（唯一权威源）、L2 聚合索引（业务路由表）与 L3 分析模板（单一范式），单技能上下文节省约 80%；
- **模型任务角色解耦**：意图分类窄判别任务使用小模型（如 25B），把顶级大模型资源留给复杂 ReAct 对话与长程推理；
- **负样本路由与约束代码化**：在 Description 中强制引入“不适用场景”负样本声明，并将时间范围、检索上限等确定性硬约束下沉为工程代码护栏。
