# 实体：宝玉

## 概述

**宝玉**（网名），本名未公开，是中文技术社区具有广泛影响力的 AI 自媒体博主、资深软件工程专家，极客时间《软件工程之美》专栏作者。

其拥有逾 20 年软件工程一线经验，早期自学编程，技术栈从 ASP、PHP、.NET、iOS 前端跨越至前沿 AI 应用与自主智能体（Agent）开发。曾历任工程师、开发经理、技术总监，后出国留学并出任海外工程经理。其在 AI 时代专注于大模型应用技术、Agent 机制普及、提示工程以及 AI 原生软件工程方法论的传播。

## 关键技术成果与实践

- **Nano Banana 城市天气提示词**：设计了风靡海内外的极简城市天气画图提示词，通过结合 Gemini 的原生联网检索能力实现仅凭城市名生成带有实时天气特效的地标艺术图，获得 Google CEO Sundar Pichai 在 Twitter/X 上的公开致谢。
- **BaoCut 视频字幕转译工具**：历时三年研发的 AI 原生音视频双语字幕转译产品。完整经历了从早期模拟人类字幕组（Whisper听写+切SRT+逐行翻译+人工校对）到基于 Agent 重构（利用 Whisper 词级时间戳完整句子对齐、术语表提取注入、脚本自动化自测验证）的架构演化。
- **Claude Agent Skill 元工具架构深度解构**：在中文社区深度翻译与技术拆解 Han Lee 的《Claude Skills Deep Dive》，系统解构了 Agent Skill 在 API tools 数组中的元工具（Meta-tool）本质、双消息注入隔离机制（用户可见极简状态 vs 隐藏的完整指令）、执行上下文动态修改（`contextModifier`）与生命周期。
- **[[concepts/概念_AI原生思维|AI 原生思维]]与研发范式倡导**：提出以模型能力边界为坐标系找需求，通过高保真原型和非舒适区语言快速试错；主张“两侧瓶颈论”，认为写码瓶颈已破除，软件工程核心竞争力向“左侧设计定义”与“右侧测试验收”转移；倡导个体像训练大模型一样推翻旧权重、构建自收敛的 Loop Engineering 成长循环。
