# 实体：Exa

## 简介

**Exa**（原 Metaphor）是一家专注于为 AI Agent、开发者与大语言模型提供神经网络搜索与定向语义索引的搜索引擎供应商。在 Agent 搜索供应链中，Exa 是**定向语义索引层（Focused Semantic Indexing Layer）**的典型代表。

## 核心定位与技术特色

1. **缩小战场的高质量定向索引**：
   - 面对全网每天数十亿垃圾网页（SEO 农场、机器生成内容等）对抗的巨大沉没成本，Exa 采取了“缩小战场”的策略，优先对 GitHub、ArXiv、Wikipedia 以及高质量专业/技术博客等信息密度极高的站点进行深度抓取与物理索引。
2. **嵌入与语义驱动检索**：
   - 采用端到端的神经语义表示（Neural Embeddings）替代传统纯关键词匹配，支持以自然语言段落或 Prompt 形式直接检索语义相似或逻辑承接的高质量网页内容。
3. **技术与学术垂类优势**：
   - 在编程代码、前沿论文、专业技术文档和深度调研等高价值场景下检索准确率极高，显著降低了 Agent 在长程推理中的幻觉与错误信息引入。
