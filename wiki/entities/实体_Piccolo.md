# 实体：Piccolo

## 概述

**Piccolo** 是由 AgentScope 与 Data-Juicer 团队联合研发、在魔搭 ModelScope 社区发布的专用决策模型（涵盖 4B、9B、27B 等不同规格）。作为面向智能体工作流、数据处理和实时交互控制的专用决策组件，Piccolo 并不生成长篇自然语言文本，而是专注于迅速理解当前环境状态、横向权衡预定义候选项，直接输出程序可无缝消费的确定性动作选择与校准概率分布。在研发体系上，Piccolo 完整践行了基于 [[concepts/概念_RSI递归自我改进|RSI（递归自我改进）]] 的自动化研发闭环。

## 核心接口与数据模型

1. **统一的决策输入输出契约**：
   - 将多样化的离散分类、打分排序和多分支路由抽象为标准四元组：**`（状态 State，问题 Question，候选项 Candidates，目标分布 Target Distribution）`**；
   - 既支持输出单一明确标签（硬标签选择），又原生支持保留连续期望分与偏好打分的软标签概率分布（和为 1.0），底层通过单次前向打分机制消除逐 Token 自回归解码开销。
2. **Context Evolving（上下文演化搜索）**：
   - 团队发现输入组织形态对决策性能具有极其显著的影响。Piccolo 将输入上下文结构（问题前置/后置、上下文重排序、重复阅读机制等）纳入自动化空间搜索；
   - 在相同模型权重不变的前提下，仅靠优化上下文布局与推理设置，全集文本 Decision Index 便从 65.05 跃升至 66.19。

## 三大核心应用场景

### 1. Game（长程连续动作决策）
具备毫秒级响应与长程时序决策能力。在动作游戏《绝区零》的复杂战斗实录中，Piccolo 依托高帧率画面截图输入，实时动态指导角色的移动、连招攻击与精准闪避，支撑执行端转化为手柄/键盘物理按键；同时适配 Mario（跳跃时机）、2048（合并方向规划）、推箱子与黑白棋（棋盘博弈选点）等经典时序决策环境。

### 2. Harness（智能体编排决策控制）
深度嵌入 [[concepts/概念_Harness_Engineering_宿主编排工程|Harness Engineering]] 宿主系统，解决 Agent 运行轨迹中的核心控制问题，覆盖六大标准化子场景：
- **工具选择**：依据任务意图与环境约束，在数十个工具中选择最适 API（如查交付日期调用订单系统）；
- **模型路由**：结合任务难度、上下文长度与预算成本动态派发底座模型；
- **上下文与记忆**：智能过滤过期无效信息（如历史天气），精确保留长期核心记忆（如用户过敏史）；
- **权限与信任**：安全门禁拦截，限制高危操作（如允许保存草稿，拒绝直接越权发送/发布）；
- **完成验收**：根据当前交付物与证据判断任务是否充分达成；
- **失败恢复**：面对网络或执行错误，判定是否重试或回退重规划。

### 3. Data（数据工程流水线全链路决策）
面向复杂数据流，提供结合语义、规则与证据的自动化判断，覆盖六大子场景：
- **数据过滤**：判断清洗、去重与质量阈值截断；
- **处理方案**：动态决定清洗与算子编排顺序；
- **产物质量**：评估生成文本的保真度与摘要事实性；
- **信息充分性**：检测材料是否存在缺项（如缺失税额时阻断计算并请求补充）；
- **证据与隐私**：敏感数据（如邮箱、身份证）在流转前强行触发脱敏；
- **工作流控制**：控制批处理管线的流转、分支与中止。

## 基准评测与对标实证

在 2026 年 11 月 2 日更新的决策模型多基准对比中，Piccolo-27B 取得以下代表性战绩：
- **JevBench Public**：准确率达到 **92.21%**（在 11 款主流参评模型中位居第一，显著超越 [[entities/实体_Jev|Jev]] 等同类决策接口）；
- **HarnessJevBench Hard**：达到 **84.41%**（排名第一），展现出在对抗性与高难度智能体 Harness 编排场景中的鲁棒性；
- **DataJevBench**：达到 **82.60%**（排名第一），验证了在工业级复杂数据流决策中的有效性；
- **Decision Index**：文本 Decision Index 达 **68.59**，多模态 Decision Index 达 **77.75**；
- **场景基准开源贡献**：团队将评测智能体运行控制与数据工程决策的两个核心基准向社区完全开源（`agentscope-ai/HarnessJevBench` 与 `datajuicer/DataJevBench`）。

## 基于 RSI 的持续进化架构

Piccolo 的能力跃迁并未依赖昂贵的人工逐条标注，而是依托一套可自动闭环的递归自改进（RSI）系统：
1. **数据治理与 13 维语义画像**：从 665 万条开源与合成数据中，基于 Data-Juicer 梳理出覆盖 13 个标注维度、551 个预定义取值的数据标签体系，全量去重并做 Benchmark 物理隔离；
2. **逐题 KL 损失与错误切片诊断**：通过监测逐题 KL 散度（模型输出概率与目标分布的偏差），按语义标签切片定位模型的薄弱能力模块。对高偏差切片定向合成数据，对低偏差充分学习样本执行降采样回放；
3. **Agentic 研发流水线闭环**：利用自研的 Agentic Data Engineering 与 DataJuicer-Sandbox，由多研究 Agent 自主协同推进“方案设计 $\to$ 构建与实验 $\to$ 结果反馈 $\to$ 诊断与更新”的闭环循环。累计执行 10+ 轮、150+ 项探索实验（耗费 6,300 GPU hours，PPU-真武810E），最终仅需 35 万条高质量样本微调即达成最优性能；
4. **模型合并与多规格拓展**：基于分项能力的互补性进行权重合并；同一套数据工程演化闭环同时下沉至轻量端侧，驱动 Piccolo-9B（文本 DI 从 46.78 升至 60.86）与 Piccolo-4B（从 39.94 升至 58.29）实现阶梯式能力进化。
