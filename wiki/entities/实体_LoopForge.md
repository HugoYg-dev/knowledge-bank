# 实体：LoopForge

## 简介
**LoopForge** 是腾讯轻量云团队打造并开源的云端自进化研发平台（GitHub：`Tencent/LoopForge`，官网：`https://loopforge.cn`）。平台针对单机 Coding Agent 在研发团队中面临的合盖断流、多人上下文割裂、自由 Vibe Coding 质量失控、日常盯单耗时与同类问题反复踩坑五大痛点，构建了集云端 7×24 工作区、共享会话、工程级 SOP、无人值守自动化与工程级 [[concepts/概念_RSI递归自我改进|RSI]] 自进化于一体的团队级研发底座。

## 核心架构与五步演进

1. **云端 7×24 小时三层运行底座**：
   - **云端隔离工作区**：按任务分配独立云端容器或安全沙箱，支持同时拉取多仓库并自动切分支，在云端完成编码、编译、单测、联调与提 MR。
   - **存算分离与自有机器接入**：支持平台托管容器与团队自有云主机/闲置开发机一键接入；执行环境与编码工具（[[entities/实体_Claude_Code|Claude Code]]、[[entities/实体_Codex|Codex]]、CodeBuddy 等）解耦；代码凭证由网关按身份临时注入并在任务结束后擦除，模型不接触明文密钥。
   - **自动快照休眠与唤醒**：闲置回收或跨机器切换时自动打包未提交修改与分支状态为云端快照，下次对话无损恢复。

2. **团队共享会话与三挡权限放行**：
   - 收敛为“一个对话同一时间只绑定一个云端工作区、只有一个 Main Bot 对接全组成员”，产品、设计、研发共享同一上下文现场；小改动由 Main Bot 直接改代码、验证并提 MR。
   - 提供**每次确认 / 智能代批 / 完全自动**三挡权限：在智能代批模式下，由**无工具、无凭证的独立审查模型**评估操作风险与当前发起人授权意图（隔离群内他人发言与提示词注入），高风险或未授权操作转交人工确认。

3. **五层标准解耦 SOP 与三层主副驾秩序**：
   - **五层解耦资产**：岗位角色（职责、编码规范、专属技能与客观门禁）、SOP 流程（拓扑与打回路径）、执行引擎（底层编码工具适配）、运行环境（云端沙箱/自有机器）、交付物契约（结构化阶段交接产物）。日常会话支持按需 `@专家角色` 进行只读咨询。
   - **三层主副驾（人 ↔ Main Bot ↔ SOP 节点）**：支持在线 IDE/终端直接修改，或通过 Main Bot 执行**暂停介入、恢复续跑、直接接管**三种受控介入。

4. **工程级 RSI 双环自进化**：
   - **单次运行内环**：SOP 节点内置编译、单测、代码规范等客观验证门禁，不通过则携带报错自动纠错自愈（设重试上限防死循环）。
   - **跨运行外环**：SOP 结束后自动回溯全链路轨迹，输出 0~100 分健康度评分，并生成“改进处方”以改写 SOP 节点拓扑、追加岗位角色防呆规范或升级质量门禁；经人审阅“一键应用”后生成新版本资产。

5. **定时巡检与 Issue 全链路自动化**：
   - **定时自动拉单与回写**：周期巡检需求池与仓库 Issue，按标签匹配修复 SOP 并将状态与 MR 链接双向回写原单据。
   - **集成分支合流与冲突自愈**：多 Issue 并行修复后自动按序合入集成分支，遇冲突自动提取上下文打回 SOP 修复并复跑门禁。
   - **零阻塞挂起**：需要人工拍板的单据进入「待我确认」队列时立即释放后台执行资源，保障日常单据持续吞吐，同时支持每日代码健康度与依赖安全巡检。

## 与 DSH Super-agent 原型对比
- 相比 [[entities/实体_DeepSeek|DeepSeek]] 的 [[entities/实体_DeepSeek_Harness|DSH]] Super-agent 研究原型（面向个人或轻量团队的异步工单调度、浅层 Router 分发、单工单单 Worker、黑盒后台自治与外部 Watchdog 监控），LoopForge 面向多人研发团队协同与工程交付，采用 Main Bot 主副驾、多角色共享工作区与五层 SOP 流水线，提供随时暂停/恢复/接管能力与内环门禁+外环 RSI 自动改写闭环。

## 工程落地现状
- 截至 2026-11-17 来源，LoopForge 已正式开源，在腾讯内部服务于 **20+ 业务**，单月自动完成 **200+ 需求与日常单据交付**。
