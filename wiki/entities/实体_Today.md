# 实体：Today

## 基本信息

- **公司/产品**：Today AI（国内最早探索 Personal AI 的团队之一）
- **创始人**：齐俊元（协作工具 Teambition 创始人；2019 年 Teambition 以 1 亿美元被阿里巴巴收购，此后先后加入阿里、字节；2025 年底开始创业押注 Personal AI）
- **产品定位**：做一个有长期记忆、会主动帮忙的 Personal AI——记住用户正在推进的目标，留意后来的变化，在合适的时候提醒，得到确认后把事情接着做下去；很多 Agent 解决"把事做完"，Today 想往前一步在人开口之前判断"现在有什么事值得做"。
- **投资方**（截至 2026-10-21 的来源披露）：IDG 资本、腾讯、五源资本、蚂蚁集团、红杉中国、传音控股、同歌创投、上海交大菡源资产。

## 产品观察与核心判断（2026-10 访谈口径）

1. **国内场景与海外分化**：海外 Muse/Instinct 的 Magic Moment 来自执行能力（订票、报销、取消订阅）；国内因移动互联网服务足够方便且生态封闭，更快表现出需求的是日程管理、To-Do List、知识管理与类 CRM 场景，价值集中于需要持续数周数月、不断加入新信息的长期任务。
2. **主动性是 Aha Moment**：主动建立在对人的理解之上，个性化源于记忆设计，两种能力耦合；用户高频反馈是"它记得"和"它懂我"；现阶段自评为 Product-Value Fit，离 PMF 尚有距离。
3. **垂直起点、通用终局**：竞争关键在 Context（拿到的用户上下文量与同 Context 下的体验交付）；不同维度上下文之间的"化学反应"本身是壁垒，故 Day One 选择通用路线；认可垂直切入打法（如 Town 从邮件起步）但认为长期会被通用产品覆盖。
4. **Evaluation 与归因优先于 Memory 单点突破**：Muse/Today/Instinct 架构相对一致、无代际级 Memory 领先；真正壁垒是扎实的 Evaluation 体系与准确归因；产品经理把人类先验认知设计成 Rubrics 代表用户当裁判；以模拟用户体系对比无历史/静态画像/30 天交互历史三种状态检验长周期交付效果。
5. **自训模型与不可能三角**：主流模型重心在 Coding 与复杂推理、对话体验不足；自训模型追求在智能、效果、成本之间找平衡，与 Harness 联合优化而非追赶 frontier model。
6. **商业化原则**：先证明 Personal AI 有用再谈赚钱；海外版订阅制、国内版暂不收费；广告易破坏信任、履约抽佣有前提、订阅早期最不伤害体验；"Personal AI 必须站在用户一边"。
