# 实体_OpenAI

全球顶尖的人工智能研究企业与实验室，以开发通用人工智能（AGI）并造福全人类为目标，是大模型及生成式 AI 领域的行业绝对引领者。

## 核心特征与贡献
- **GPT 系列大语言模型**：从 GPT-1 到 GPT-4o 及 o1/o3 推理系列模型，确立了以 Transformer 为基础的缩放定律（Scaling Law）与 RLHF 强化学习对齐范式。
- **颠覆性应用生态**：发布 ChatGPT、DALL-E、Sora、Codex 等核心产品，推动 AI 从实验室走向全球数亿用户与企业生产力工作流。
- **开发者与 API 生态**：提供 Assistants API、Function Calling、微调与 Batch 接口，成为现代智能体（AI Agent）构建的底层基石。

### gpt-oss 系列（开放权重推理模型）
- **发布时间**：2025 年 8 月（自 GPT-2 以来首批开放权重模型），采用 Apache 2.0 许可证。
- **模型规模**：包含 gpt-oss-20b 和 gpt-oss-120b（解码器 Transformer + MoE 架构），聚焦推理与蒸馏。
