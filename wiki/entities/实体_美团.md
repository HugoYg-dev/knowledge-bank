# 实体：美团

## 简介

**美团（Meituan）** 是中国领先的科技零售与本地生活服务平台，涵盖外卖、团购、酒店旅游、即时零售与出行等丰富业务场景。在人工智能领域，美团围绕本地生活高频、低容错、强履约时效的特征，构建了从底层分布式系统、大规模搜索推荐、风控审核到全栈 AI 智能体应用的完整工程体系。

## 核心 AI 业务与工程实践

### 1. 本地生活搜索与查询理解
- **美团搜索架构**：服务高峰期 QPS 达数万次，针对本地化“地域”约束与多履约形式聚合的业务特性，构建了离线深度挖掘与在线 SMT/NMT-BERT 协同的高精度查询改写体系，详见 [[entities/实体_美团搜索|美团搜索]]。

### 2. 全栈生活服务智能体（Full-Stack Agent）
- **业务编排与非阻塞容错**：在行程规划等复杂场景中，串联天气、酒店、景点与路线四级 API 链路，支持单点异常下的降级与部分结果交付，保障高可用交互。
- **多轮需求澄清机制**：面对用户模糊 Query（如“找好吃的”），通过核心特征（品类/位置/预算/人数）渐进收敛，并设立超时默认推荐兜底，防止无限循环追问。
- **综合推荐评分模型**：融合用户画像 Embedding（0.4）、带时间衰减的实时交互行为（0.3）、库存阈值（0.2）与上架新鲜度（0.1），兼顾个性化与商业履约。

### 3. AI Coding、工程可靠性与安全风控
- **三道安全防线**：在代码生成与执行中引入“静态代码审查（Semgrep/SonarQube）+ 隔离容器单测沙箱 + 人工复核审批”的立体防御。
- **并发控制与长任务管理**：通过全局 `task_id` 驱动长任务优雅取消，使用 Redis 分布式锁（`SET NX EX` 配合 Lua 校验删除与 WatchDog 自动续期）防范并发死锁。
- **评论风控与内容审核**：将高风险审核拆分为规则层、输入输出层、权限层与测试层，结合决策置信度矩阵进行分级处理。

### 4. 评测与架构治理
- **客观验证体系**：主张将“客观确定性验证（70%）+ 用户反馈确认（20%）+ 专家人工抽检（10%）”结合，避免纯主观评分偏差。
- **架构协议标准化**：倡导跨应用通用工具遵循 MCP 协议标准，业务私有逻辑沉淀为具体 Skill。
