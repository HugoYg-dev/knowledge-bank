# 实体：腾讯元宝

## 基本信息

- **类型**：AI 智能助手 / 企业级 AI 搜索开放平台
- **归属**：腾讯
- **定位**：面向 C 端用户的 AI 智能助手，以及面向 B 端开发者与智能体（Agent）生态的高性能低延迟网络搜索基础设施

## 核心架构与工程创新

1. **面向 Agent 的双向信号反馈机制**：
   - 搜索端向 Agent 输出检索条目的权威等级、发布时间与排序满意度；
   - Agent 端反向回传命中引用、推理思考过程与答案打分（Answer Reward）作为监督信号，驱动 Teacher 排序模型训练并蒸馏至 Student 模型上线，支持天级增量迭代。
2. **倒排与向量千亿级混合索引**：
   - 将关键词倒排索引与语义向量索引融合进同一张千亿规模索引库，实现 94% 以上的高召回率，平均检索耗时仅 8ms。
3. **Gist Token 排序计算压缩**：
   - 在索引构建阶段预先将网页全文压缩为 100 维 Gist Token 向量并缓存在 [[concepts/概念_KV_Cache_键值缓存|KV Cache]] 中；
   - 在线精排时直接复用 Gist Token 缓存，计算量仅与检索词长度相关，节省约 30% 在线推理算力。
4. **垂直行业插件系统（时效性补齐）**：
   - 针对股票、天气、航班等超高频动态数据，建立连接 13 个垂直行业 157 个头部信源（如腾讯自选股、飞常准、携程、京东）的插件体系；
   - 直接调取合作方 API 封装为结构化卡片与网页结果合并返回，解决网页爬取时效滞后与数据版权壁垒。
5. **信源质量三级打分与 AIGC/GEO 防护**：
   - 实施“站点、账号、页面”三级质量评级，对抗低质水文与针对 AI 搜索引擎优化的 GEO 内容。

## 接入形态与分发协议

- **RESTful API**：支持按量付费与灵活参数配置（条数控制 `Cnt`、站点过滤、时间范围与垂直行业限定）；
- **[[concepts/概念_MCP协议|MCP（Model Context Protocol）]]**：入驻腾讯云 MCP 广场，提供标准化的 `initialize`、`tools/list` 与 `tools/call` 协议接入，支持 Codex 等智能体开箱即用；
- **Agent Skill**：发布于腾讯 SkillHub，支持智能体通过指令一键安装。
