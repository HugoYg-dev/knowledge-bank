## 核心要点

- 单轮 RAG 直接围绕当前问题检索和生成；多轮 RAG 还要处理指代、省略和任务前后依赖，通过问题改写、会话状态、历史压缩与信息融合构造可检索的完整问题。
- RRF 不直接比较不同检索器的异构原始分数，而是按各路排名计算倒数秩并累加；平滑常数通常取 60，但需在业务数据集上评测，检索源权重也应由线上 A/B 测试决定。
- 检索采用粗排与精排两阶段：BM25 或双塔向量模型从大规模索引快速保召回，Cross-Encoder 只对少量候选做细粒度相关性判断，以计算成本换取更高精度。
- Markdown 应按标题、段落和代码块切分并保存完整标题路径；PDF 需通过版面分析识别标题、正文、表格和图片，并处理跨页段落。切片还应保留父子关系与相邻块信息，而非固定字数生切。
- 长文处理可按任务在递归切分、Map-Reduce 摘要、树状摘要和按需检索之间选择：整体理解偏摘要，具体事实查找偏检索。
- Memory 模块包含当前会话的消息、任务状态和工具结果，以及数据库或向量库中的稳定偏好与历史事实；检索后还需处理记忆更新、冲突、过期和隐私，冲突判断可结合时间与置信度。
- Agent Loop 是管理模型调用、工具执行、状态更新和终止条件的通用运行框架；ReAct 是其中一种可插拔策略，工程上还需设置最大步数、单步超时、权限校验和工具失败兜底。
