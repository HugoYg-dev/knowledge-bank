## 2. 核心要点

1. **两类根本不同的事实性错误病因**：
   - **存储失败（Empty Shelves）**：知识在训练时未固化进权重（语料未包含或未学会），参数内无该事实。
   - **访问失败（Lost Keys）**：知识已沉淀于权重中，但当前提问通路受阻、语序上下文未对齐，模型未能唤起取出。
2. **完全相反的两张工程预算表**：存储失败需要将算力与预算投向数据清洗、扩增语料与参数规模；访问失败则必须将预算花在提问方式优化、选项核验、思考计算开销以及精准触发检索的策略上。现有系统常将其混同，导致资金误配。
3. **松严双尺测试方法学**：
   - **松尺子测存储**：复刻预训练最熟悉状态，提供原文截断接龙，答对即算存储成功。前沿模型编码率高达 **95–98%**，知识存储接近饱和。
   - **严尺子考提取**：撤除原文，正问与倒问各出两道同义改写题目（共 4 题全对才算掌握），前沿模型闭卷失败率仍达 **26–34%**。
4. **排除干扰变量与打破逆转诅咒（Reversal Curse）**：同义改写经 104 次检验确认表现无显著波动，排除了“没听懂特定措辞”；倒问偏离预训练语序，提取链路大幅变长；采用四选一选择题（再认测试），9 个模型的倒问成绩反超正问，证明模型权重中已经存储了双向关联，单纯生成答不出是唤起缺陷。
5. **缺口形态提供客观证据**：
   - 冷门事实与热门事实编码率仅差约 5%，但闭卷召回率差距扩大到 20% 以上（Gemini-3-Pro 从 84.6% 跌至 63.3%），证明冷门事实的主要瓶颈在于访问而非存储。
   - Gemma3 架构从 1B 扩展至 27B，编码失败率从 85% 降至 23%，但剩余错误中提取失败占比持续飙升，印证参数扩展修好的是存储，修不好访问。
6. **思考机制（Thinking）的记忆翻找本质**：即使在无逻辑推理链的单跳事实题中，开启思考能挽回 40–65% 已编码却答错的事实（对未编码事实仅能挽回 5–15%）。COLM 2026 论文证实即使思考内容为无意义重复句，仅增加前向计算 token，就能通过**计算缓冲与事实启动**（注意力寻址与线索词唤起）找回事实。
7. **公开事实四阶排查阶梯**：低成本探测（调语序/少线索） $\to$ 选项核验（单选再认） $\to$ 开启思考（中间 token 翻找） $\to$ 触发外部检索（RAG）。反思了自适应 RAG（Adaptive-RAG）直接按“答不出”触发检索的粗暴判定，避免不必要的延迟和上下文膨胀。

## 3. 关键机制与工程推论

### 3.1 实验设计与变量隔离矩阵

论文通过严密的实验设置堵住了模型的一切“借口”：

```
提问测试矩阵：
├─ 存储检测（松尺子：开卷截断接龙）──> 测得 95-98% 编码率（确认货架有货）
└─ 提取检测（严尺子：闭卷 4 题全部答对）
   ├─ 同义改写（2 种表述）─────────> 控制措辞变量，排除“没听懂”
   ├─ 正问 vs 倒问 ─────────────────> 检验提取链路长度（倒问链路长、易中断）
   └─ 自由生成 vs 四选题再认 ──────> 破解逆转诅咒（选择题 9 模型倒问>正问，确认已存双向关联）
```

### 3.2 思考机制的记忆翻找与成本控制

传统观念认为思维链（CoT）或思考模型仅在复杂逻辑推导中起效。WikiProfile 与《Thinking to Recall》揭示了全新机理：
- **事实启动与注意力寻址**：多步骤输出的中间 token 扩大了自注意力机制在前向计算时的寻址空间，模型自主吐出的相关领域词汇充当了隐式提示词（Priming Cue），重新打通了被阻塞的权重通路。
- **成本账本与分诊**：思考并非免费午餐，它消耗高昂的计算资源与输出延迟。盲目全量开启思考是对成本的严重浪费；必须在识别出属于“已编码但单轮未唤醒”的高价值查询时局部触发。

### 3.3 生产环境排查阶梯与自适应 RAG 优化

针对公开百科事实，工程落地应遵循由廉价到昂贵、由存量到增量的分步分诊流程：

| 阶梯 | 动作 | 目标机制 | 计算与系统成本 |
| :--- | :--- | :--- | :--- |
| **第一步：低成本探测** | 调整提问语序、补充少量上下文线索 | 顺应预训练语序，缩短提取链路 | 极低（常规推断开销） |
| **第二步：选项核验** | 将候选词包装为单选题测试再认能力 | 降低自由生成阈值，触发辨识记忆 | 低（单轮短 token 生成） |
| **第三步：开启思考** | 允许模型生成中间思考 token | 借助计算缓冲与隐式线索唤起记忆 | 中/高（消耗大量推理 token） |
| **第四步：触发外部检索** | 接入 RAG 系统引入外部文档上下文 | 解决权重中真正缺失的知识 | 高（网络 I/O、检索延迟、长上下文输入） |

> **私有与时效数据特例**：团队私有业务知识与最新时效动态天然不存在于模型预训练权重中，应当直接路由至第四步（外部检索），严禁在前三步空耗探测算力。
