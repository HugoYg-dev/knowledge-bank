# 月之暗面 Agent 开发岗面试复盘

## 来源信息

- 作者：AIGC小白入门记
- 发布时间：2026-07-22（正文署名时间为 2026-07-21 22:15）

## 核心要点

- 项目以 ReAct 循环实现长线任务：每轮把 Thought、Action 和真实 Observation 追加到上下文，直到输出最终答案或达到最大步数。
- 短期记忆采用“滑动窗口 + 触发式总结”：常驻 System Prompt 与最近 2-3 轮完整对话，超过 Token 警戒线后把更早历史压缩为目标、进度、阻塞与约束摘要。
- 文章给出的触发方案包含软硬双阈值：软阈值为窗口的 70%，异步生成摘要并缓存；硬阈值为 90%，同步阻塞并完成摘要替换。替换前复制完整上下文，并原子更新历史区以避免并发状态错乱。
- 后续摘要采用增量叠加：已有摘要与新增对话在再次触发时合并压缩，而非每次重算全部原始轮次；原始会话仍需持久化，用于审计回放、摘要重建和长期记忆检索。
- 长期记忆不是每轮注入，而是由意图路由判断当前问题是否依赖历史，再从向量库召回 Top-K；短期记忆常驻上下文，长期记忆按需加载，以减少无关信息干扰。
- 工具过多时使用“意图识别 + 渐进式披露”：先加载工具名称与一句话描述，选中类别后再加载少量完整 Schema。文中示例称 50 个工具由完整加载的 20,000 Token 降至两阶段共 2,200 Token，但该数据来自作者示例计算。
- RAG 实现采用语义切分、BGE-large-zh-v1.5、Milvus IVF_FLAT、Top-20 向量召回与 BGE-reranker-v2 Top-5 精排；检索审计日志记录召回和精排前后的文档、分数及最终上下文，以区分召回、排序与生成问题。
