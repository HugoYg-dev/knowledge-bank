# ms-swift倾情奉献：决策模型的从原理到上手定制

## 来源信息

## 核心要点

1. **决策模型范式兴起与生态分化**：2026 年 9 月 TypeSafe 发布首个规模化决策模型产品 [[entities/实体_Jev|Jev]]，定位为 System 1 决策模型，完全不生成自由文本，输入上下文与候选集合后直接单次前向输出校准概率分布。赛道迅速分化出三大技术路线：**判别式打分路线**（如 Jev、Laya）、**生成式概率截取路线**（如 [[entities/实体_OpenAI|OpenAI]] Decisions 接口，截取首 Token 并在生成分布上归一化）、以及**联合解码路线**（如 Cloudflare 开源的 Clef，建模整组问题答案的联合分布）；开源社区亦同步涌现 JEV-27B-VL、Clef、OmniJev、NanoJev、NeoHorse 等多样化实现。
2. **传统分类与生成式任务 vs 决策模型比较**：传统分类依赖专属分类头且缺乏跨任务零样本泛化能力；通用生成模型处理选择题时逐 Token 采样解码耗时且概率严重饱和过度自信（置信度常堆积在 1.0）；决策模型将题型统一抽象为是非、多选一、有序打分，单次前向输出受限选项集合的归一化分布，具备极低推理延迟与可比拟置信度。
3. **开源决策模型的五种架构类型划分**：依据评分头信号来源、候选项序列化方式、候选间交互机制与多问题联合建模策略，模型可划分为五类：
   - **token 读出型**（如 JEV-27B-VL）：在输出分布上按 verbalizer 读出各选项对数概率，几乎不引入新参数，直接支持 [[concepts/概念_LoRA_低秩适应微调|LoRA]] 微调与 vLLM 部署；
   - **隐状态读出型**：直接对 Transformer 隐向量加分类打分头，骨干网络选择自由；
   - **联合解码器型**（如 Clef）：用重头建模多问题交互，一次前向回答一整组结构化问题；
   - **逐候选显式交互型**（如 NanoJev）：每个选项与上下文拼接独立送入模型打分再归一化，精准但计算开销随选项数线性增长；
   - **多模态专用型**（如 OmniJev）：端到端覆盖图像/视频多模态输入与有序评分。
4. **严格适当评分规则与损失函数谱系**：决策模型损失函数均属于适当评分规则（Proper Scoring Rules），在真实分布处取得最优。结构由“共享基础项 + 校准项”构成：基础项为**掩码软交叉熵（Masked Soft Cross-Entropy / Log Score）**，单精度计算且不截断概率，避免高置信度错误梯度消失；校准项包含衡量累积分布差距的**有序概率得分（RPS）**、**Brier 得分**（均方概率误差）与**序数交叉熵**。ms-swift 分别为 JEV-27B-VL 预设 `distill_rps`、Clef 预设 `smooth_brier`、OmniJev 预设 `ce_rps`。
5. **ms-swift 训练支持与自动化精度管理**：框架通过 `--task_type decision` 一键开启决策模型支持，内置注册 `open_jev_jev:all` 语料。底层自动化实现：全精度激活评分头参数（偏置与温度维持单精度）；同时监控逐题准确率与联合解码场景的每记录准确率；评分头权重独立保存并通过自动钩子加载。
6. **两级温度标定机制与 ECE 显著改善**：ms-swift 在训练后自动挂载温度标定回调，生效温度为**全局温度 × 题型相对温度**，同时校正整体偏差与特定题型偏差（如是非题欠自信与打分题过自信）；采用样本外两折交叉验证（记录按奇偶对半拆分互相拟合）；实测使 JEV 的期望校准误差（ECE）从 0.00268 降至 0.00143，**降幅达 46.7%**，留出实验显示 Brier 分下降 9.5%，且预测答案与准确率严格不变。
7. **通用模型转换路径与置信度级联实战**：ms-swift 提供 `generic_decision` 转换路径，普通因果 LM（如 Qwen3.5-4B）无需更换架构，仅通过 LoRA 微调即可转换为决策模型，准确率从随机水平提升至 0.6667。在韩美医学执照考试对比中，三款决策模型错误检出能力 AUROC 达 0.856–0.935，最低置信度 20% 样本覆盖了 56%–91% 的错误案例；若将低置信度样本路由至大模型复核，整体准确率提升 6–9 个百分点，总成本仅为全量大模型方案的 25%–33%。

## 关键引文

> “当置信度本身是产品的一部分时，不能直接把未经验证的生成概率当作可靠置信度。”
> 
> “两级温度相乘得到生效温度：全局温度捕捉模型整体的置信度偏差，每题型相对温度捕捉题型特有的偏差。是非题欠自信、打分题过自信的情况可以同时纠正。”

## 核心机制与原理解析

### 1. 决策模型的五种架构类型

| 架构类型 | 评分头信号来源 | 候选交互机制 | 典型代表 | 优缺点与适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **token 读出型** | 语言输出层 Logits | 输出分布按 verbalizer 读出 | JEV-27B-VL | 几乎不引入新参数，直接支持 LoRA 微调与 vLLM 高并发部署；适合从既有生成模型迁移 |
| **隐状态读出型** | 编码器隐状态向量 | 线性/MLP 评分头打分 | 常见判别基座 | 骨干选择自由度高，适合无自然语言输出层的紧凑特征底座 |
| **联合解码器型** | 多问题任务表示 | 联合注意力捕捉跨问题依赖 | Clef | 一次前向直接建模全套问题联合概率分布，适合表单/清单批量审计 |
| **逐候选显式交互型** | 拼接候选的隐向量 | 独立送入编码打分后归一化 | NanoJev | 候选间精确深度交互建模，计算量随候选数线性增长，适合候选较少且语义复杂的场景 |
| **多模态专用型** | 视觉编码器 + 跨模态层 | 端到端视觉打分头 | OmniJev | 面向图像与视频质量评估及有序评分专项优化 |

### 2. 严格适当评分规则与损失函数体系

决策模型优化严格遵循统计学上的**适当评分规则（Proper Scoring Rules）**：只有当预测概率与真实后验概率完全吻合时，期望损失达到全局最小值。

```
                   [决策模型损失函数谱系]
                             │
     ┌───────────────────────┴───────────────────────┐
     ▼                                               ▼
[共享基础项]                                     [专用校准项]
掩码软交叉熵 (Log Score)                          ├─ RPS (有序概率得分: 累积分布差距)
(单精度计算, 无概率截断, 退化为 CE/KL)              ├─ Brier Score (均方概率误差)
                                                 └─ 序数交叉熵 (保留档位序关系)
```

- **掩码软交叉熵（Masked Soft Cross-Entropy）**：基于对数评分（Log Score），支持独热硬标签与平滑软分布；全精度掩码计算避免截断，使极端过度自信的错误预测依然具备有效回传梯度。
- **有序概率得分（Rank Probability Score, RPS）**：衡量预测离散概率分布与真实标签在有序档位上的累积分布距离（CDF 差值的平方和），惩罚跨档位严重误判。
- **Brier 得分**：预测概率与真实指示向量的均方误差 $\frac{1}{K}\sum (p_k - y_k)^2$。
- **ms-swift 预设损失组合**：
  - `distill_rps`：结合教师模型蒸馏软目标与有序概率得分，适配 JEV-27B-VL；
  - `smooth_brier`：结合标签平滑交叉熵与均方 Brier 得分，适配 Clef；
  - `ce_rps`：结合纯对数得分与 RPS，适配 OmniJev；
  - `scoring`：不含额外校准项的基准评分模式。

### 3. 两级温度标定机制

为了消除模型在不同题型上的系统性置信度偏差，ms-swift 设计了级联标定：

$$\tau_{effective} = \tau_{global} \times \tau_{task\_relative}$$

- **全局温度 $\tau_{global}$**：拉平模型整体的平均过度自信或欠自信；
- **题型相对温度 $\tau_{task\_relative}$**：针对是非题（常呈欠自信）与分级打分题（常呈过自信）分别微调，实现细粒度校准；
- **交叉验证拟合**：训练后回调将校准集记录按奇偶二折切分，在对侧子集上求解最优温度；温度仅单调拉伸 Logits，预测 Label 严格不变，ECE 下降 46.7%。

### 4. generic_decision 通用微调命令

通过 ms-swift，将通用生成大模型转换为 Jev 风格判断模型只需一条命令：

```bash
swift sft \
    --model Qwen/Qwen3.5-4B \
    --model_type generic_decision \
    --task_type decision \
    --loss_type distill_rps \
    --tuner_type lora --target_modules all-linear \
    --dataset open_jev_jev:all \
    --output_dir output
```

训练完成后，使用 `swift infer` 即可执行零生成文本的纯概率推理，并可通过 `--metric acc` 自动化评估。
