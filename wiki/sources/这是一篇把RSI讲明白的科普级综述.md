# 来源摘要：这是一篇把"RSI"讲明白的科普级综述！

- **来源信息**：Datawhale / 赵志民（2026-09-19）
- **核心议题**：解析递归自我改进（Recursive Self-Improvement, RSI）的真实工程现状，澄清“自我改进”、“有界闭环”与“递归自我加速（智能爆炸点火）”的本质界限。

## 核心要点

1. **RSI 的四层可观察标准**：
   - **持久改进（Persistent Improvement）**：变化写入参数、记忆、工具或驾具，跨任务持久生效；
   - **自主闭环（Autonomous Loop / 有界 RSI）**：系统在划定边界内自主发现问题、做实验、评估并采纳更优版本；
   - **递归增益（Recursive Gain / Ignition 点火）**：新版本不仅基准得分更高，且更擅长产生下一次改进，实现改进能力的复利积累；
   - **稳健可控（Robust & Controllable / 开放式 RSI）**：增益在固定资源与隐藏评测下持续泛化，且不以指标作弊、系统复杂度失控或对齐退化为代价。
2. **历史五次边界推进**：
   - **前史（1981-2017）**：从 EURISKO（暴露奖励作弊/自欺欺人）到 AlphaZero（沙盒规则写死的自对弈持久权重改进）；
   - **第一次推进（2022-2023，推理与记忆）**：以 Reflexion 为代表，通过自然语言反思与情景记忆错题本提升任务能力，但底座参数不变；
   - **第二次推进（2022-2024，自造数据与微调）**：STaR（推理链逆向提示自举）与 SPIN（与历史版本自对弈微调），实现权重级持久化，但评价标准与真实目标仍由人类固化；
   - **第三次推进（2022-2025，AI 评估权）**：从 Constitutional AI（规则提示打分）到 Self-Rewarding（自打分 DPO）再到 Meta-Rewarding（元评判），打分权移交导致“尺子变弯”、标准漂移；
   - **第四次推进（2023-2026，驾具代码自修改）**：从提示词迭代（OPRO）、工作流搜索（ADAS, AFlow）到自修改编排代码（Self-Harness, DGM, AgentX），改代码比改权重更低廉可控；
   - **第五次推进（2025-2026，学习与研究过程闭环）**：SEAL（自定学习计划）、WebEvolver（环境沙盘世界模型）、Motus2（物理机器人自演进），以及 AIDE² 与 Bilevel Autoresearch 等元研究系统。
3. **关键现状与反向证据**：
   - 目前工程已实现前两层（持久改进与有界闭环），个别系统展示出净正改进（Level 1 Net Positive），但**尚未跨过第三层递归增益的点火门槛（Ignition）**；
   - AI4AI-Bench 显示多数 Agent 仅擅长修工程、调工作流，触及底层训练算法核心时能力仅为 0.250；AIDE² 呈现出代码复杂度膨胀与死代码累积。
4. **阻挡开放式 RSI 的四道门禁**：
   - ① **验证器外部锚**：评估器和权限边界必须独立于被进化系统之外，防止奖励作弊；
   - ② **分布跨越与防坍缩**：自生成数据容易导致模型坍缩，必须经受分布外隐藏测试；
   - ③ **真实递归增益**：需验证改进行为本身是否具备复合增益；
   - ④ **对齐与审计可扩展性**：能力增长必须伴随安全监控与审计能力同步演进。
