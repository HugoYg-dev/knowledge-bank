# 再见RAG！AI知识库还得是SAG，又快又准～

## 核心要点

1. **传统 RAG 面临多跳推理断链与黑盒调优瓶颈**：
   - 扁平向量检索与工业标准混合检索（全文+向量+重排序，如 FastGPT 默认架构）依赖字面与语义表面匹配。面对跨多文档的复合多跳推理（如“收购了 B 公司的企业，其 CTO 后来加入了哪个项目？”），因问题未提及中间实体（如 CTO 姓名），检索线索必然在单跳后断裂；
   - 传统 RAG 调优极度依赖切块大小、重叠比、向量模型与重排分数的经验调整，属于高耦合的“炼丹式”调试，容易陷入“按下葫芦浮起瓢”的噪音权衡陷阱。

2. **GraphRAG 的离线高成本与动态维护困境**：
   - [[concepts/概念_Graph_RAG_知识图谱增强检索|GraphRAG]] 与 HippoRAG 2 等方案通过离线全量提取三元组并构建全局知识图谱突破多跳瓶颈；
   - 但其离线构图的 LLM 调用成本巨大（中等数据集需数万元），且图谱一旦构建，面对频繁新增、删除文档时的动态重算与维护开销极高，对于中小型企业轻量级知识库过于沉重。

3. **SAG 核心范式：查询时动态超边（Query-Time Dynamic Hyperedges）**：
   - 广州智跃深空（Zleap）开源的 **SAG（SQL-Retrieval Augmented Generation）** 提出了基于 SQL 关系型数据库的折中破局路线；
   - **入库前移（事项化建模）**：入库时不依赖机械的定长滑动切块，而是利用 LLM 将每个文档切片提炼为结构化的“事项卡片（Event）”，并抽取其涉及的“实体（Entity）”，存入关系型 SQL 数据库与向量库；
   - **查询时动态激活**：放弃全局静态图谱的预构建，在查询发生时由 SQL 的 `JOIN` 操作动态把具有共同实体的事项连接起来，就地组合成局部超边关系网，将图结构构建时机完全推迟到查询时。

4. **双轨检索与隐式实体二轮自动多跳穿透**：
   - **首轮并行召回**：输入 Query 时，一边由向量库执行语义搜索召回相关段落，另一边从 Query 中抽取显式实体（如“B公司”、“CTO”），由 SQL 筛选出命中的第一批事项；
   - **新实体挖掘与二次激活**：扫描首轮命中的事项上下文，自动挖掘出问题中未提及但起桥接作用的关键新实体（如“张三”），立即触发第二轮 SQL 关联查询，精准拉取后续文档（如“张三加入盘古项目”）；三份线索全部到位后交由模型综合生成，化偶发的多跳推理为确定性的关系图遍历。

5. **评测 SOTA 与对底层向量模型的极强鲁棒性**：
   - **MuSiQue 地狱难度基准测试**：在最具挑战的多跳基准 MuSiQue（要求最多 4 跳且不许跳步）上，SAG 的 Recall@5 达到 80.04%，相较于基于神经科学海马体索引与 Personalized PageRank 的 HippoRAG 2（65.13%）高出近 15 个百分点；
   - **向量模型解耦与抗弱模型表现**：消融实验显示，将 SAG 底层向量模型替换为普通的弱开源模型时，其他高级 RAG 准确率暴跌约 10%，而 SAG 依然稳定在 80% 左右。原因在于多跳主干由确定性的 SQL 实体关联驱动，弱化了对向量距离的依赖，天然能免疫企业内部特定未微调“行业黑话”的影响。

6. **确定性可解释性与生产级轻量集成**：
   - **排障路径透明**：检索全过程输出为清晰的 SQL 与实体追踪日志（LLM 提取实体 -> 同义词扩展 -> SQL 执行链路），排障从盲目调参转变为程序员熟悉的看日志修 Bug；
   - **工程扩展与 Agent 底座**：已在约 5 亿条数据规模的生产环境完成部署并维持秒级响应；工程落地推荐将 SAG 封装为标准 MCP 工具接入成熟的前端与权限平台（如 FastGPT），或直接作为 [[entities/实体_Claude_Code|Claude Code]] / [[entities/实体_Codex|Codex]] 等 Agent 调用的高确定性结构化记忆底座。

## 关联概念与实体

- **核心概念**：
  - [[concepts/概念_SAG_动态超边结构化检索增强生成|概念_SAG]]：基于查询时动态超边的 SQL 检索增强生成架构。
  - [[concepts/概念_Graph_RAG_知识图谱增强检索|概念_GraphRAG]]：以图结构组织知识的检索增强生成方法对比。
  - [[concepts/概念_Graph_RAG_知识图谱增强检索|概念_知识图谱RAG]]：知识图谱在 RAG 中的应用与离线/在线构图权衡。
  - [[concepts/概念_RAG基础流程|概念_RAG基础流程]]：传统文本切分、向量化、检索召回与重排全景。
  - [[concepts/概念_Lazy_Graph_RAG_惰性知识图谱增强检索|概念_Lazy_Graph_RAG]]：语义搜索与低成本图谱构建结合的演进路径。
- **关联实体**：
  - [[entities/实体_Claude_Code|实体_Claude_Code]]：可通过 MCP 协议将 SAG 作为多跳检索底座的本地 Coding Agent。
  - [[entities/实体_Codex|实体_Codex]]：支持 MCP 接入的本地智能体开发环境。
