# 向量没归一化的量纲灾难：相似度全是 0.9 排查与修法

## 来源信息
- **标题**：手把手教你：相似度全是 0.9？向量没归一化的量纲灾难｜AI工程师踩坑实录·第10篇
- **作者**：大雾的小屋
- **发布时间**：2026-11-18（实验版本时间戳：2026-11-06，`bge-small-zh-v1.5`）
- **原文链接**：https://www.cnblogs.com/dawudexiaowu/p/23703439

## 核心要点
- **隐蔽的分数失真根因**：检索与训练照常运行无报错，但未归一化向量直接计算点积时，相似度分数会出现量纲爆炸（几十甚至上百）或挤在 `0.85~0.95` 一团，导致 RAG 拒答阈值失效、分数不可解释且跨查询不可比。
- **数学机制拆解**：点积满足 $\text{Dot}(a, b) = \cos(\theta) \cdot \|a\| \cdot \|b\|$，其中两个向量的范数随模型、池化方式与文本内容变化，是不受控的自由变量，会直接“劫持”原本的语义相似度。
- **真机复现数据**：在 Win11 + CPU 环境下，使用 `transformers` 原始 API 提取 `bge-small-zh-v1.5` 的 CLS 向量（6 段文档范数在 `6.4~7.2` 之间），未归一化点积分数达 `11.7~36.2`（跨度 24）；双侧归一化后余弦相似度回归 `0.232~0.734`。
- **双侧归一化是唯一正解**：必须在**入库流水线**与**查询阶段**两侧同时执行 L2 归一化，只做一侧等于没做；归一化后点积与余弦在数学上完全等价。
- **索引与框架避坑纪律**：`sentence-transformers` 虽对 bge 默认自带 Normalize 模块，仍需显式传入 `normalize_embeddings=True` 以防换模踩坑；结合 [[concepts/概念_近似最近邻搜索|ANN 索引]]（如 FAISS）时应采用“归一化向量 + IP（内积）索引”组合，避免归一化后误用 L2 距离导致排序方向写反。
- **真实文本余弦分布规律**：实际文本 [[concepts/概念_Embedding与向量检索|Embedding]] 多集中在语义空间同一半球，余弦很少低于 0，通常分布在 `0.2~0.8`，拒答阈值需基于业务问答对实测分布标定，而非想当然取 `0.5`。

## 实验复现与机制拆解

### 1. 实验设置与封装差异陷阱
- **模型与 API 选择**：选用 `bge-small-zh-v1.5`。若直接调用 `sentence-transformers` 的 `encode()`，由于 bge 的配置默认附带 Normalize 模块，输出向量范数恒为 `1.0`，点积与余弦完全一致。必须使用 `transformers` 原始 API 提取 CLS 向量，才能还原自写特征提取代码时的原始未归一化现场。
- **测试集**：6 段文档（1 段 CUDA 相关、1 段 PyTorch 相关、4 段完全不相关且其中 1 段刻意加长）配合 1 条查询。

### 2. 实测对比与量纲失真表现
- **范数分布**：6 段文档原始 CLS 向量范数在 `6.4` 到 `7.2` 之间。
- **分数对比**：未归一化点积区间为 `11.7 ~ 36.2`；双侧归一化后余弦相似度回归 `0.232 ~ 0.734`。

![两种分数量纲对比](https://img2024.cnblogs.com/blog/2824078/202611/2824078-20261118100104880-1549417855.png)

- **三种工程危害**：
  1. 拒答阈值（如“0.55 以上算相关”）直接失效；
  2. 单看分数（如 `36.2`）无法判断相关性强弱；
  3. 跨查询不可比（A 查询最高分 `36` 与 B 查询最高分 `20` 不能说明 A 更可信）。
- **排序劫持风险**：本机实验中因 6 段文本 CLS 范数恰好接近，Top-1 仍为 CUDA 文档未发生排序翻转；但部分模型范数跨度可达 `1~20`，一旦更换模型、改用 mean pooling 或更换语料，高范数的无关文本随时会劫持排序。

![点积的构成机制](https://img2024.cnblogs.com/blog/2824078/202611/2824078-20261118100104832-1743064270.png)

### 3. “相似度全是 0.9”的同源成因
当部分模型或池化方式（如平均池化配合特定缩放）输出向量的范数天然接近 `1` 时，点积约等于余弦再乘以约 `0.9` 上下的系数（本质仍是混入了不受控的范数因子），导致所有文档分数挤在 `0.85 ~ 0.95` 之间，同样造成阈值失效与排序区分度丧失。

## 工程修法与实战纪律

```python
vecs = vecs / np.linalg.norm(vecs, axis=1, keepdims=True)
q = q / np.linalg.norm(q)
sims = vecs @ q   # 此时点积 == 余弦
```

1. **双侧前置归一化**：将向量归一化固化在切片入库流水线中，并在查询侧同步执行，不在查询时对库内原始向量临时补救。
2. **显式传参防切换风险**：使用 `sentence-transformers` 时显式声明 `normalize_embeddings=True`，避免日后切换无内置 Normalize 模块的模型时隐性失效。
3. **度量和索引配套**：在 FAISS 等向量索引中，采用“先归一化 + IP（内积）索引”作为余弦检索标准组合；不建议归一化后使用 L2 索引并将距离充当相似度（数学虽单调等价，但距离越小越相似，方向相反极易在取 Top-K 时引入低级 Bug）。
4. **分布标定阈值**：鉴于文本向量余弦多落在 `0.2 ~ 0.8`，RAG 拒答或重排阈值应基于真实问答对分布实测确定，不预设 `0.5` 为中线。
