## 核心要点

1. **单会长对话与超越 Chat 的界面范式**：[[entities/实体_Muse|Muse]] 的主聊天界面被设计成一段持续的长对话，跨会话保留记忆并支持用户连续派发任务或随时打断；为应对复杂话题引入侧边对话隔离上下文，并以聊天气泡界定想法边界；更重要的是突破“一切皆 Chat”的狭隘认知，采用为用户量身定制的富交互 [[concepts/概念_Presentation_Tools_表现层工具化|Artifacts]]（如可交互开支追踪看板、行程单），替代冗长的纯文本回复。
2. **主动执行的高门槛与透明度设计**：Muse 配备专属云端电脑环境（文件系统、终端 CLI 与浏览器），能够长期自主推进任务；系统将主动发消息的打断门槛设得极高，仅在出现有意义进展或必须人工介入时才主动通知；同时设立直观的状态说明、活动记录与「目标」标签页，彻底解决后台不可见引发的用户信任危机。
3. **专属云端电脑与双安全域隔离架构**：同一台云端机器被严格划分为两个互不信任的安全域——运行 Agent 的 Harness 处于隔离的执行单元中，预期处理不可信数据，无真实凭证与 root 权限；与外部世界（连接器与所有网络出站流量）的每一次交互，必须经由独立的宿主侧哨兵 [[concepts/概念_Personal_Agent_个人智能体|Sentinel]] 审批，从架构层杜绝单点攻陷。
4. **结构化 Human-in-the-Loop 与致命三要素防线**：针对 Simon Willison 提出的「致命三要素」（访问私人数据、接触不可信内容、对外通信），Muse 设立多层纵深防御：外部数据进入上下文一律标记为不可信输入；采用带明确“接受/拒绝”的结构化审批卡片防范“横幅盲视”；服务支持读写权限分离；邮箱连接器采用确定性规则过滤验证码与重置链接；线上支付采用一次性虚拟卡号。
5. **记忆透明度与夜里学习（Nightly Learning）**：用户的记忆文件完全透明且支持本人阅读和编辑；系统在夜间自动将全天反思与交互沉淀整合进长期记忆，持续推进未完项目并主动衍生新提议，有效解决了用户不知道 AI 还能帮自己做什么的冷启动障碍。
6. **扎克伯格对 Personal Agent 的长期战略研判**：马克·扎克伯格指出 Personal Agent 不同于企业级编程助手（如 [[entities/实体_Claude_Code|Claude Code]]），其核心在于融入家庭生活与维护人际关系；强调将“分寸感”（对内了解用户隐私、对外办事绝不泄露敏感属性）作为个人超级智能的专门预训练与后训练能力；并由 Signal 创始人 Moxie Marlinspike 主导构建机密虚拟机项目保障端到端隐私。

## 关键引文

> “同一台电脑上有两个彼此隔离的安全域，而不是一个拥有整台机器 root 权限的大模型 Agent。运行单元预期会处理不可信的数据，所以安全检查模型、凭证服务、连接器执行进程等都放在它外面，攻击者无法在运行单元里关掉这些防护。” `[架构设计]`
>
> “我们把「分寸感」当作个人超级智能需要专门训练的能力。你的 Muse 会知道很多关于你的事，还要到外部世界替你办事，却不能随意透露敏感信息。” `[核心原则]`
>
> “Simon Willison 在 2025 年 6 月提出的「致命三要素」，是 Muse 一直紧盯的问题：访问私人数据、接触不可信内容、能够对外通信。如果 Agent 同时具备这三项能力，攻击者就很容易诱骗它读取你的私人数据，再发给攻击者。” `[安全基准]`
