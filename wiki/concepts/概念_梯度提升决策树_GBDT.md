# 梯度提升决策树 (Gradient Boosting Decision Tree, GBDT)

## 基础理论

**梯度提升决策树 (GBDT)** 是一种经典的集成学习算法，属于 Boosting 家族。其核心理念是由 Jerome Friedman 在 2000 年代初奠定的。

### 负梯度拟合残差
GBDT 通过加法模型 (Additive Model) 与前向一步一步逼近 (Forward Stage-wise Additive Modeling) 的方式进行迭代训练：
1. **模型迭代**：初始化一个弱学习器，此后每一步迭代训练一颗新的决策树（通常是回归树 CART）。
2. **负梯度拟合**：新一轮的弱学习器 $h_m(x)$ 并不直接去拟合真实标签 $y$，而是去拟合损失函数在当前模型 $F_{m-1}(x)$ 处的**负梯度 (Negative Gradient)** 方向：
   $$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F(x) = F_{m-1}(x)}$$
3. **残差逼近**：当损失函数为均方误差 (MSE) 时，负梯度恰好等于真实值与当前预测值之差，即**残差 (Residual)**。通过沿着负梯度方向拟合，GBDT 在函数空间执行梯度下降，最终将多个弱学习器累加成一个预测能力极强的模型。

## 四大主流 GBDT 框架横向对比

在工程实践中，存在四个最为广泛使用的 GBDT 演进框架：**XGBoost**、**LightGBM**、**CatBoost** 和 **NGBoost**。它们在关键架构设计上存在以下显著差异：

### 1. 树生长策略 (Tree Growth Strategy)
- **XGBoost**：使用 **层级生长 (Level-wise)** 策略。树会按层横向分裂。这种方法由于对称分裂，容易控制树的深度和避免过拟合，但对增益较小的节点也会进行无谓的分裂计算。
- **LightGBM**：使用 **叶子节点生长 (Leaf-wise / Best-first)** 策略。每次迭代优先分裂带来最大纯度增益（分裂误差降低最多）的叶子节点。这能产生比 Level-wise 更低的误差和更深的树，但在小数据集上容易过拟合，需通过 `max_depth` 和 `num_leaves` 严格正则化。
- **CatBoost**：使用 **对称树 (Symmetric Trees)** 策略。每层节点都执行完全相同的分裂标准（Oblique Splits）。这类树的结构极其平衡，能大幅降低过拟合风险，并能够在 CPU/GPU 上并行进行超快速的模型推理（Inference）。

### 2. 类别特征处理方式 (Categorical Feature Handling)
- **XGBoost**：不原生支持高维类别特征，传统做法需在数据预处理阶段手动进行 One-Hot 编码或 Target 编码（较新版本增加了部分内部支持，但在大类别特征处理效率上依然有限）。
- **LightGBM**：直接支持类别特征。它采用直方图优化算法，通过对类别特征的值按照目标均值排序，并利用一维直方图进行最优分裂点划分，效率远高于 One-Hot 编码。
- **CatBoost**：**类别特征处理的黄金标准**。在内部使用一种改进的 **排序目标编码 (Ordered Target Encoding)** 结合 One-Hot。它在数据随机排列的基础上，利用当前样本之前的历史样本统计信息来替换类别标签，从而彻底消除了普通 Target 编码引起的“目标泄漏 (Target Leakage)”和过拟合问题。

### 3. 分层采样机制与分裂算法 (Sampling & Splitting)
- **XGBoost**：使用传统贪心搜索 (Exact Greedy) 寻找分裂点，或在海量数据下使用基于百分位数的近似分箱算法（Approximate Algorithm）。
- **LightGBM**：引入 **基于梯度的单侧采样 (Gradient-based One-Side Sampling, GOSS)**。由于梯度较大的样本代表误差较大（对提升有更多贡献），GOSS 保留所有高梯度样本，并在低梯度样本中随机采样一小部分（在计算增益时给予补偿）。这既减少了 80% 以上的训练样本量，又几乎没有牺牲分裂精度。
- **CatBoost**：引入 **最小方差采样 (Minimal Variance Sampling, MVS)**。MVS 是一种根据样本梯度的大小加权进行随机抽样的方法，使得分裂时的方差降到最低，保证了高层决策树分裂的稳定性。

### 4. 概率预测与不确定性量化 (Natural Gradient Boosting)
- **NGBoost**：由斯坦福团队开发，专为 **概率预测 (Probabilistic Prediction)** 而生。传统的 GBDT 只输出点估计（例如预测房价为 100 万），而 NGBoost 通过更新基学习器来预测一个完整的**目标概率分布参数**（例如预测房价服从均值为 100 万、标准差为 10 万的正态分布）。
- **自然梯度 (Natural Gradient)**：NGBoost 使用自然梯度代替传统欧几里得空间梯度。自然梯度考虑了概率分布空间（黎曼流形）的几何特征，基于 KL 散度进行优化，从而在拟合参数化概率分布（如高斯分布、拉普拉斯分布）时拥有极强的数学稳定性和准确性，能够精确做**不确定性量化 (Uncertainty Quantification)**。

## 结构化/表格数据建模选型逻辑

在实际业务或竞赛中，针对不同场景的选型逻辑推荐如下：

| 框架名称 | 核心优势 | 劣势 | 推荐适用场景 |
| :--- | :--- | :--- | :--- |
| **CatBoost** | 原生分类变量支持极好，防过拟合能力极强，开箱即用，推理速度快。 | 训练速度相对较慢（特别是 CPU 模式下），大类别编码内存消耗大。 | **重分类变量特征**的表格数据集；不希望投入大量时间调参的任务。 |
| **LightGBM** | 训练速度极快，内存占用非常低，支持海量和高维稀疏数据。 | 在小数据集上非常容易过拟合。 | **海量大样本数据**（如千万级）；高维稀疏特征；需要快速迭代调参的场景。 |
| **XGBoost** | 功能完善，参数控制非常细致，在各类平台上生态极其稳定。 | 训练耗时且内存消耗相对较大，缺乏高维类别特征的极速处理机制。 | **中等规模数据**的稳定 Baseline 建立；需要极其精确的参数微调和定制损失函数的场景。 |
| **NGBoost** | 提供完整的概率区间和不确定性估计。 | 训练开销显著大于其他三者（因为每个分布参数都需要拟合一棵树）。 | **金融精算（如保险定价）、医疗诊断、天气预报**等对决策置信区间高度敏感的领域。 |
