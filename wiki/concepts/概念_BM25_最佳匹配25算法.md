# 概念_BM25_最佳匹配25算法


## 定义

BM25（Best Matching 25）是信息检索中的排名函数，基于概率检索框架，是 TF-IDF 的改进。根据查询词在文档中的词频、文档长度等特征计算相关性分数。

## 特点

- 基于关键字匹配，不依赖语义理解
- 对精确关键字匹配效果好
- 不擅长捕获语义相似（同义词、近义表达）
- 实现简单、速度快

## 实现

- Python 库：`rank_bm25` 的 `BM25Okapi`
- 分词：文中按空白分词（简单方式，可改进为更复杂分词）
- 索引：`tokenized_docs = [doc.page_content.split() for doc in documents]`


## 代码搜索中的符号保真作用

在 AI Coding Agent 场景（如 [[entities/实体_zvec-grep|zvec-grep]]）中，BM25 承担 Ranked Lexical Retrieval 的职责：
- 比纯 grep 多了基于词频、逆文档频率和长度归一化的相关性排序；
- 比纯向量检索更尊重代码中的真实标识符（如类名 `AuthService`、特定错误名），有效防止向量语义泛化冲淡关键符号匹配。
