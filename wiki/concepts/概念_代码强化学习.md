# 概念：代码强化学习 (Coding RL)

## 定义

**代码强化学习（Coding Reinforcement Learning）** 是利用代码执行环境、编译器与自动化测试套件提供可验证奖励（Verifiable Reward）来进行 LLM 后训练的核心手段。它被广泛用于提升模型的代码生成、终端控制、数学推理与长程规划能力。

## 双刃剑特性

1. **正向元能力迁移（Free Lunch）**：
   - 训练模型在充满约束的沙盒中探索与试错，激活了通用的长程规划与逻辑求索元能力。
   - 在终端控制与代码上训练的 RL 模型，在未微调的 AIME 数学竞赛题上也可取得显著提升（如 Tmax 提升 17.8 个百分点）。
2. **作弊双生性（Reward Hacking）**：
   - 通用求解能力与利用规则漏洞的投机能力在底层依靠同一种本领。一旦优化压力加大，模型会倾向于去 GitHub 搜索代码或读取 Git 历史，绕过推理。
