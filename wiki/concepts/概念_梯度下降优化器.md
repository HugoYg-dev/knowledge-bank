# 概念：梯度下降优化器


## 定义

通过梯度寻找函数最小点的一类算法。改善梯度下降的两个常用工具：梯度之和（一阶矩）和梯度平方之和（二阶矩）。

## 五种方法对比

### 原版梯度下降（Vanilla GD）
- delta = -learning_rate * gradient
- 只按梯度方向迭代，易陷入局部极小值/鞍点/高原

### 动量（Momentum）
- 借鉴物理学（无摩擦碗滚球），累积衰减的梯度之和（一阶矩）
- sum_of_gradient = gradient + previous_sum * decay_rate
- decay_rate 通常 0.8-0.9
- 优势：移动更快、逃脱局部极小值、通过高原区

### AdaGrad
- 跟踪梯度平方之和（二阶矩，无衰减）
- delta = -lr * gradient / sqrt(sum_of_gradient_squared)
- 处理稀疏特征：更新多的特征未来更新少
- 优势：避开鞍点；缺点：平方和只增不减，后期几乎停止

### RMSProp
- 在 AdaGrad 基础上加衰减因子（梯度平方的衰减和）
- sum_sq = previous * decay_rate + gradient² * (1-decay_rate)
- 比 AdaGrad 快，方块保持可控大小

### Adam
- 同时使用一阶矩（Momentum）+ 二阶矩（RMSProp）
- beta1=0.9, beta2=0.999
- 深度学习常用最佳选择

## 总结口诀

- 动量用一阶矩衰减率获得速度
- AdaGrad 用无衰减二阶矩处理稀疏特征
- RMSProp 用二阶矩衰减率加速 AdaGrad
- Adam 同时用一阶+二阶矩，通常最好

## 现代深度学习 12 种主流优化器全景分类

随着模型规模从经典神经网络演进至超大规模语言模型（LLM），优化器的设计考量不仅包含收敛步数，更关键的是每一次参数更新的**计算复杂度**、**显存状态占用（Optimizer States）**与**流形几何约束**：

| 优化器分类 | 代表算法 | 核心机制与状态开销 | 核心优势 | 局限性与权衡代价 |
| :--- | :--- | :--- | :--- | :--- |
| **基础动量与步长自适应** | **SGD (w/ Momentum)** | 维护一阶矩动量缓冲（1x 状态） | 结构最简单、显存最低 | 无坐标自适应步长，对学习率极其敏感 |
| | **AdaGrad** | 累加历史所有梯度平方（无衰减二阶矩） | 自动自适应稀疏特征更新 | 分母累积单调递增，后期步长过早收敛至零 |
| | **RMSprop** | 引入指数移动平均（EMA）追踪二阶矩 | 历史观测平滑衰退，克服 AdaGrad 停滞 | 缺乏动量平滑，仍需调谐基础学习率 |
| | **Adam** | 结合一阶矩（动量）与二阶矩（RMSprop） | 坐标级自适应，鲁棒性高，深度学习最通用基线 | FP32 二阶矩维护需 2x 状态（如 1B 参数需 8GB 显存），L2 正则被扭曲 |
| **正则解耦与状态压缩** | **AdamW** | 将权重衰减（Weight Decay）与自适应更新解耦 | 规范化正则效果，成为大模型训练黄金标准 | 显存状态开销与 Adam 相同（仍需 2 份状态缓冲） |
| | **Adafactor** | 将 2D 矩阵 $n \times m$ 二阶矩分解为行与列统计量 $n+m$ | 显存状态从 $O(nm)$ 压至 $O(n+m)$，大幅省显存 | 因子分解引入统计近似误差，训练前期稳定性稍逊 |
| | **Lion** | 移除二阶矩，仅取动量-梯度混合的符号（Sign） | 仅维护一阶动量（1x 状态），省显存且收敛较快 | 坐标更新幅度绝对值统一，必须大幅调小学习率 |
| | **AdEMAMix** | 融合快（Fast）与慢（Slow）双重动量 EMA + 二阶矩 | 兼顾快速响应与长周期方向一致性，泛化更佳 | 增加额外动量状态缓冲，显存开销大于 AdamW |
| **矩阵几何与曲率估计** | **Shampoo** | 针对矩阵参数构造左右双侧矩阵值预条件子 | 捕获跨参数维度的相关性，改善病态曲率 | 需高频计算矩阵求逆/SVD，算力与显存开销大 |
| | **SOAP** | 将梯度旋转至 Shampoo 特征基后执行 Adam 更新 | 结合二阶基变换与 Adam 的坐标自适应 | 频繁特征值分解带来较高的系统与计算开销 |
| | **Muon** | 使用 Newton-Schulz 迭代对 2D 动量进行谱正交化（[[concepts/概念_Muon优化器|概念_Muon优化器]]） | 均衡奇异值谱范数，使深层矩阵更新平滑稳定 | 仅适用于 2D 隐藏层权重；Embedding/输出层仍需 AdamW 混合协同 |
| | **Sophia** | 定期轻量采样对角 Hessian/Gauss-Newton 曲率估计 | 兼顾曲率感知与步长截断，抗非凸损失震荡 | 仍需周期性采样前向/反向计算曲率，调度复杂度稍高 |

## 工程实操与选型权衡陷阱

### “步数减少 vs 单步耗时” 性能陷阱（Step Time Trap）
在评估或替换新型优化器时，不能仅看**总训练步数（Steps to Target Quality）**的减少，必须端到端度量**硬件墙钟时间（Wall-Clock Time）**与**显存峰值（Peak Memory）**：
- **反直觉算例**：某二阶/正交化优化器可能使模型达到目标 Loss 所需的训练步数减少 **20%**，但由于单步涉及复杂的矩阵运算（如特征值分解或频繁 Kernel 切换），导致单步耗时（Step Time）增加 **30%**。
  $$\text{总耗时比率} = (1 - 0.20) \times (1 + 0.30) = 0.80 \times 1.30 = 1.04$$
  这意味着即使步数缩减了 20%，整体训练时间反而增加了 **4%**，在实际计算集群中得不偿失！
- **基准测试黄金原则**：
  1. **首选 AdamW 作为基准线**，在固定算力预算（Compute Budget）下进行全面的学习率搜索（Learning-Rate Sweep）；
  2. **显存受限场景**：优先评估 Adafactor 或 Lion，释放宝贵显存以增大 Batch Size 或参数量；
  3. **深层大模型架构**：评估 Muon 等矩阵正交化优化器时，必须核查参数覆盖范围（Hidden vs Embedding/Head）并采用批处理张量算子降低 Kernel Launch 开销。
