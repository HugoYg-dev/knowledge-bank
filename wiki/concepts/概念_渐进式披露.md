# 概念：渐进式披露

## 定义

**渐进式披露（Progressive Disclosure）** 是一种源自人机交互（HCI）和系统架构的设计原则。在 AI Agent 上下文工程和复杂知识管理（如 LLM Wiki）中，指**不一次性向用户或大模型展示全量冗余信息，而是按照“总览 -> 目录/索引 -> 详细词条 -> 底层原始文件”的层级，根据当前需求按需动态加载细节**。

## 在 AI 智能体与知识库中的应用

1. **降低认知与上下文负荷**：在 LLM Wiki 中，AI 查询知识时先读取全局目录 `INDEX.md`，定位目标概念后，再精准打开对应的 `wiki/concepts/xxx.md` 或 `raw/` 物理文献，避免一次性将上万份文档塞入窗口导致上下文爆仓。
2. **生成式 UI（Generative UI）**：在交互界面上，优先展示概览简报或核心指标，用户点击深入时再展开详细推理轨迹或数据报表。
3. **工具 Schema 分层加载**：工具数量较多时，第一阶段只向模型暴露工具名称和一句话描述，意图路由选中类别后，第二阶段再加载少量完整 JSON Schema。这样可同时缩减上下文占用和工具选择干扰。
