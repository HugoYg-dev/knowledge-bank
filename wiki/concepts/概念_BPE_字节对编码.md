# 概念：BPE 字节对编码

## 定义

**BPE（Byte Pair Encoding，字节对编码）** 是一种基于数据统计驱动的子词（Subword）分词算法。其最初作为通用的数据压缩算法被提出（Gage, 1994），后由 Sennrich 等人引入自然语言处理领域（2016），并成为当代绝大多数大语言模型（如 GPT 系列、LLaMA 系列等）在文本预处理阶段的标准分词范式。

BPE 通过在无监督语料上迭代统计并合并最高频共现的相邻字符对（或字节对），从最底层细粒度的基础单元逐步向上构建出包含常见前缀、词根与高频词汇的受限词表（Vocabulary）。

## 核心机制与算法流程

BPE 分词器的构建与使用分为两个独立阶段：**词表训练（Learning）** 与 **文本分词编码（Tokenizing）**。

### 1. 词表训练流程

1. **初始化基础词表**：收集海量文本语料，预切分后将每个单词拆散为最小的基础字符（或 256 个 UTF-8 字节）序列，并在词尾添加边界标记（如 `</w>`），词表初始化为所有基础字符集合。
2. **共现频率统计**：在整个语料库中遍历并统计所有相邻符号对（Symbol Pairs）的共现频次。
3. **高频对贪心合并**：挑出当前出现次数最高的一对连续符号 $(s_i, s_j)$，将其合并为一个全新的复合符号 $s_{new} = s_i + s_j$，并将该新符号加入词表。
4. **迭代直至达到预设上限**：将语料库中所有匹配的 $(s_i, s_j)$ 替换为 $s_{new}$，重复步骤 2 和 3，直到合并规则达到预设次数，或词表规模扩张到目标大小（如 32,000、50,000 或 128,000）。

### 2. 文本编码与推断

在模型推断或训练准备阶段，分词器严格按照上述训练过程中学得的**合并规则优先级**（Merge Rules），自底向上逐轮将待切分文本拼合为当前词表中存在的最长子词 Token 序列。

## 与主流分词算法对比

| 算法 | 构建策略 | 核心合并/裁剪依据 | 典型应用模型 |
| :--- | :--- | :--- | :--- |
| **BPE** | 自底向上（Bottom-up） | 相邻字符对的最高统计共现频次（局部贪心） | GPT-2/3/4、LLaMA |
| **WordPiece** | 自底向上（Bottom-up） | 合并后能够最大化提升语言模型似然度（互信息增益） | BERT |
| **Unigram** | 自顶向下（Top-down） | 从超大候选集合出发，按删减对整体概率损失最小原则反向剪枝 | T5、SentencePiece 默认 |

## 优势与工程局限

### 核心优势

- **平衡词表规模与序列长度**：有效解决了传统词级（Word-level）模型造成的 OOV（Out-of-Vocabulary，未登录词）困扰，同时避免了纯字符级（Character-level）序列过长导致的注意力计算灾难。
- **高压缩率与计算加速**：高频词直接压缩为单个 Token，大幅缩减自回归生成的序列长度，提升推断吞吐量并节省算力。

### 关键局限与系统性代价

1. **局部贪心非全局最优**：BPE 每一步仅贪心合并当前最高频对，切分出的总序列长度通常并非全局最优（相比动态规划最短路径搜索）。
2. **破坏底层语义与算术结构**：
   - 掩盖字母结构：高频词（如 `strawberry`）被整体打包，模型无法通过注意力感知其内部字符细节，导致简单的字母计数失败。
   - 算术与数位混乱：从左往右固定长度的数字分块与人类从低位到高位的竖式算术相悖，破坏进位感知。
3. **跨语言不平等与成本偏见**：词表分配高度倾斜于高资源语言（如英语），低资源或非拉丁语系文本切分碎片化严重，导致相同的语义在非英语语系中消耗数倍乃至数十倍的 Token 计算预算。
4. **Glitch Tokens 安全隐患**：分词语料与预训练语料不对齐时，收录的冷门 Token 未能在上下文中充分学习，对应的权重嵌入呈随机状态，易被用于隐蔽 Prompt 注入与对抗攻击。
