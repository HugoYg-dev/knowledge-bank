# 概念：LLM 文本生成解码策略

在自回归大型语言模型（LLM）中，模型最终的输出是一个高维 Logits 概率分布向量。如何从这个概率向量中选择出最终生成的 token 决定了文本的风格、流畅度、多样性与准确性。这就需要使用不同的**解码策略（Decoding Strategies）**。

不同的解码策略在**计算资源、文本多样性（创造性）与语义准确性**之间进行着不同维度的权衡。

---

## 四大核心解码策略

### 1. 贪婪搜索 (Greedy Search)
- **定义**：最基础、最直接的确定性解码策略。在生成的每一步，模型都简单地选择当前概率最高（Logits 最大值）的单个 token，并将其输入到下一步的自回归预测中。
- **特点**：
  - **单步最优**：只关注当前时刻的局部概率最大化，不考虑后续序列的累积概率。
  - **高度重复**：由于其确定性本质，贪婪搜索容易在生成长文本时陷入无限“死循环”或生成极度单调、重复的句子。
  - **确定性输出**：对于给定的 Prompt，其输出完全固定（相当于 Temperature 趋于 0 的极限状态）。
- **适用场景**：问答、数值计算、分类任务等仅需唯一标准答案的确定性场景。

### 2. 多项式采样 (Multinomial Sampling)
- **定义**：在每一步生成时，不再机械地选择概率最大的 token，而是以每个 token 预测出来的概率作为权重，在整个词表（或被筛选过的候选池）中进行随机概率摇号采样。
- **控制机制**：为了防止采样到语义完全不通的冷门词，通常会结合温度与截断参数进行约束：
  - **Temperature (温度)**：平滑或陡峭概率分布。
  - **Top-k 与 Top-p (核采样)**：截断概率长尾，保证候选池中的词均在合理概率范围内。
- **特点**：
  - 极大提升了生成文本的多样性与创造性，能表现出不同的行文风格和新鲜词汇。
  - 有一定概率生成逻辑脱靶或语义不通顺的“幻觉”文本。
- **适用场景**：故事创作、诗歌生成、创意文案编写、日常闲聊等多样性要求高的任务。

### 3. 束搜索 (Beam Search)
- **定义**：为了解决贪婪搜索“只看当前单步”的局限，束搜索尝试逼近全局累积概率最大化。
- **工作机制**：
  - 引入束宽（Beam Width，记为 $K$）。
  - 在生成第 $t$ 个 token 时，不仅考虑一个最优，而是维护 $K$ 个累积概率最高的半成品候选序列。
  - 在生成第 $t+1$ 个 token 时，对这 $K$ 个候选序列进行扩展，分别计算它们与新 token 组合后的全局累积概率乘积，重新排序后仅保留概率最高的前 $K$ 个新序列（即“束”）。
  - 重复上述过程，直至遇到停止符或达到长度限制，最后从 $K$ 个最终序列中挑出全局累积概率最大的那条输出。
- **特点**：
  - **全局近似最优**：能有效避免开头选了高概率词而导致后续崩塌的尴尬，比贪婪搜索更能生成流畅、长程连贯的优质文本。
  - **计算开销较高**：由于需要并行计算并存储 $K$ 个分支的自回归预测，其显存与计算资源占用是贪婪搜索的 $K$ 倍。
  - 缺乏多样性，通常倾向于生成中规中矩、语义安全但缺乏新意的文本。
- **适用场景**：机器翻译（Machine Translation）、代码生成（Code Generation）等高度强调语义严格对齐与准确性的结构化输出场景。

### 4. 对比搜索 (Contrastive Search)
- **定义**：这是一种较新的解码策略，旨在克服束搜索和贪婪搜索易陷入重复、多项式采样易逻辑脱靶的通病，兼顾**文本流畅度**与**话题新颖度（多样性）**。
- **数学逻辑与惩罚项**：
  在第 $t$ 步生成时，从候选集 $V^{(k)}$（通常是概率前 $k$ 个 token）中选择能最大化以下对比指标的 token $x$：
  $$x_t = \arg\max_{w \in V^{(k)}} \left\{ (1 - \alpha) \cdot P(w \mid x_{<t}) - \alpha \cdot \max_{j < t} \{ \text{Sim}(h_w, h_{x_j}) \} \right\}$$
  其中：
  - $P(w \mid x_{<t})$ 是模型预测的原始条件概率，代表**流畅度（Fluency）**。
  - $\max_{j < t} \{ \text{Sim}(h_w, h_{x_j}) \}$ 是**退化惩罚项（Degeneration Penalty）**。它计算当前候选 token 的隐藏状态表示向量 $h_w$ 与已生成序列中所有历史 token 的隐藏向量 $h_{x_j}$ 之间的最大余弦相似度（Cosine Similarity）。
  - $\alpha \in [0, 1]$ 是平衡超参数。
- **特点**：
  - **阻断死循环**：退化惩罚项能在模型试图反复输出相同短语时给予重罚，从而强迫其跳转到其他新话题/新词汇。
  - **高连贯性与新颖性**：通过对比隐藏向量相似度，不仅避免字面重复，还在深层语义多样性上进行了约束。
- **适用场景**：超长文本生成、小说故事创作、开放式报告生成等容易在后期产生语义退化与重复的场景。

## 温度参数与幻觉/创造力权衡机制

### 1. 数学本质
LLM 的“温度”（Temperature，$T$）参数控制输出概率分布的平滑度，直接影响创造力与事实准确性之间的平衡：
在 Softmax 归一化之前，将每个候选 token 的原始对数几率（Logits）除以温度值 $T$：
$$P(x_i) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

### 2. 参数取值区间的工程表现
- **高温（$T > 1$）**：分布更平坦，各 token 之间的概率差距被缩小，更多低概率词被选中。输出更加多样、富于创意，但逻辑发散和事实性**幻觉风险显著上升**。
- **低温（$T < 1$）**：分布更陡峭尖锐，概率集中于少数最高概率词。输出更保守、严谨、准确，但行文多样性与创意受限。
- **$T \to 0$**：Softmax 退化为 $\text{argmax}$（贪婪搜索），输出完全确定且可复现。

### 3. 生产实践选型指引
- **事实性与逻辑确定任务（摘要、精准问答、代码编写、数据提取）**：使用较低温度（$T \in [0.0, 0.3]$），压缩幻觉空间，确保输出可靠性。
- **创作性任务（文案写作、头脑风暴、角色扮演）**：适当提高温度（$T \in [0.7, 1.0]$），激活多样性与联想能力。
- **长思维链推理模型特性**：推理模型（如 DeepSeek-R1、o1 等）在事实抽取任务中有时会因过度思考而出现“想象力发散”，本质机理与高温扰动相似，因此更需严格约束解码参数与温度边界。

## 策略对比与权衡维度

| 解码策略 | 计算复杂度 | 文本多样性 (创意性) | 语义准确性 (确定性) | 重复/死循环风险 |
| :--- | :--- | :--- | :--- | :--- |
| **贪婪搜索 (Greedy)** | 最低 ($\mathcal{O}(1)$) | 无 | 高 | 极高 |
| **多项式采样 (Multinomial)** | 较低 ($\mathcal{O}(1)$) | 极高 (取决于 Temp) | 中/低 (易幻觉) | 最低 |
| **束搜索 (Beam Search)** | 较高 ($\mathcal{O}(K)$) | 低 | 极高 | 中 |
| **对比搜索 (Contrastive)** | 中等 ($\mathcal{O}(k \cdot t)$) | 较高 | 较高 | 极低 |
