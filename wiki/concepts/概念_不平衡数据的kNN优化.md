# 不平衡数据的 kNN 优化

## 传统 kNN 的瓶颈与大类支配问题
在传统的 $k$ 最近邻算法（kNN）中，未知样本的分类预测是通过对最近的 $k$ 个邻居进行**多数投票（Majority Voting）**来决定的。然而，这种简单的多数表决机制在处理类别不平衡数据集时存在严重的瓶颈：
- **大类支配**：由于数据集中多数类（大类）的样本数量远远多于少数类，所以在任意未知样本的 $k$ 个邻居中，大类样本出现的概率显著增高。
- **失效场景**：当测试样本实际上属于少数类，并且在空间上极其贴近该少数类时，如果设定的超参数 $k$ 较大，邻居圈中仍不可避免地会混入较多的大类样本。如果大类样本的个数超过了少数类，多数投票就会错误地将该样本判定为大类，导致少数类样本“永远无法被正确分类”。

---

## 优化方案一：距离权重 kNN（Distance-weighted kNN）

### 核心原理
距离权重 kNN 突破了传统多数投票仅看“样本个数”的限制。它将每个近邻的投票权重设为其与测试样本之间距离的倒数：
$$ w_i = \frac{1}{d(x_{test}, x_i)} $$
- 当测试样本距离某个邻居非常近时，该邻居的投票权重 $w_i$ 将趋近于无穷大。
- 即使在 $k$ 个最近邻中多数类样本的数量占据了绝对优势，由于少数类样本距离测试样本更近，其极高的单票权重可以轻松抵消多个远距离大类样本的低权重累加。

### 工程实现
在 Python 的 `scikit-learn` 库中，该方案并非默认配置。需要显式地通过 `weights='distance'` 参数进行启用：
```python
from sklearn.neighbors import KNeighborsClassifier

# 启用距离权重 kNN
clf = KNeighborsClassifier(n_neighbors=7, weights='distance')
clf.fit(X_train, y_train)
```

## 优化方案二：动态调整 $k$ 算法（Dynamic $k$ Tuning）

### 核心原理
该算法对全局固定一个超参数 $k$ 的局限性进行了优化。它根据每个测试样本周边的局部类别分布，动态收缩 $k$ 的范围，以防止少数类被邻居中的多数类淹没。

### 动态调整的三步逻辑
对于每一个测试样本 $x_{test}$：
1. **寻找近邻**：按照预设的全局标准 $k$ 值寻找 $k$ 个最近邻。
2. **统计基数**：识别出这 $k$ 个邻居所代表的所有类别。对于每一个出现的类别，统计其在**整个训练集**中的总样本数。
   - *例：在 $k=7$ 个邻居中，有 4 个大类样本和 3 个少数类样本。经查询，大类在训练集中共 40 个样本，少数类共 3 个样本。*
3. **动态收缩 $k$**：计算当前邻居代表的各类别在训练集中样本数最小的那个值（简称为 $\text{min\_samples}$），然后将当前样本的决策邻居个数更新为：
   $$ k' = \min(k, \text{min\_samples}) $$
   此时，只对这前 $k'$ 个最近邻执行多数表决。

### 算法优势
- **防少数类淹没**：如果少数类样本被包含在了前 $k$ 个最近邻中（说明它在附近），算法将迅速把 $k$ 限制在少数类的最大可用样本数以内。大类样本将无法通过大数量占据主导地位，从而保护了少数类的分类决策。
- **保持全局评估**：如果少数类原本就没有出现在前 $k$ 个最近邻内，则说明它不在测试样本附近，$\text{min\_samples}$ 计算出来的仍是大类别的样本数（较大），此时 $k'$ 将保持不变（即 $k' = k$），算法会继续执行 holistic 的全局评估，不会因为局部噪音而损失泛化能力。

### 缺点
该算法尚未被主流的开源机器学习库（如 `scikit-learn`）原生支持，需要开发者自行编写自定义预测逻辑来实现。

## 方案对比

| 维度 | 距离权重 kNN | 动态调整 $k$ 算法 |
| :--- | :--- | :--- |
| **计算复杂度** | 与传统 kNN 类似，仅增加权重的倒数计算 | 每次预测需额外统计邻居类别的训练集样本数，开销稍大 |
| **易用性** | 极高，Scikit-Learn 直接支持（`weights='distance'`） | 需要手动实现，工程集成成本较高 |
| **核心机制** | 调整权重的量级（Value Weighting） | 调整邻居的搜索边界（Range Tuning） |
| **防噪音能力** | 对极近的孤立噪音点较为敏感 | 保持了对没有少数类区域的泛化评估 |
