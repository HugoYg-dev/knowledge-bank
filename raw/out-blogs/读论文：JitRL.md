# 读论文：JitRL - 免梯度更新的 LLM Agent 测试时强化学习

> **论文信息**：
> - 标题：**Just-In-Time Reinforcement Learning: Continual Learning in LLM Agents Without Gradient Updates**
> - 会议：ICML 2026 Spotlight
> - 链接：https://arxiv.org/abs/2601.18510

---

## 1. 论文核心
JitRL是新加坡国立大学团队的 ICML 2026 Spotlight 论文，提出免训练的测试时策略优化：全程冻结模型权重，检索经验记忆估计动作优势值，直接调制模型输出 logits，不做任何梯度更新。

## 2. 问题背景
LLM Agent 部署后权重冻结，难以持续适应新环境；传统强化学习算力贵、有灾难性遗忘风险；把经验写进提示词的上下文学习受长度限制，且表达不了难以文字化的技能。 

## 3. 方法闭环
推理时检索相似历史轨迹、估计优势值、调整 logits 后选动作；每轮任务结束由评估器模型给轨迹做步级奖励归因，折扣累加成回报，把（状态, 动作, 回报）三元组存进记忆库，形成闭环。 

## 4. 优势值估计
状态价值是相似邻居回报的平均，动作价值是同动作邻居回报的平均，两者相减得优势值；没见过的动作按不确定就乐观的原则给探索加成，记忆越充足加成越小，自动从探索转向利用。  

## 5. 理论保证
论文证明原 logits 加贝塔倍优势值这条加法规则，是 KL 散度约束下策略优化目标的精确闭式解；随记忆积累，检索估计逼近真实价值，整体策略逼近 KL 正则最优策略。 

## 6. 工程实现
有对数概率接口的模型用序号 token 的 logprob 做 logits；黑盒模型让模型自报置信度再换算（verbalized logit），Gemini、GPT、DeepSeek 这类 API 模型都能直接用。 

## 7. 实验结果
WebArena 最终成功率 51.35%，最强免训练基线 43.00%；留出测试集上 60.00% 对微调方案 WebRL 的 46.06%；Jericho 文字游戏 Zork1 平均 53.0 分，梯度训练的 GRPO 只有 16.2 分。 

## 8. 成本对比
WebRL 训练用 H200 集群约 154 小时、估算约 9900 美元；JitRL 全部走 API 调用约 290 美元，与其他免训练方法同量级，比 WebRL 便宜超过 30 倍。 

## 9. 系列定位
和 EvolveR 那期同属经验库驱动进化这条主线，区别在两个关键选择：EvolveR 把轨迹蒸馏成不断压缩整理的文字原则库，最后靠 GRPO 把检索和用法训进参数；JitRL 不对经验做抽象，只攒原始的状态动作回报三元组，全程零梯度，让记忆库直接充当价值函数，在推理时把检索出的优势值加到 logits 上。ProcMEM 是方法上最近的免梯度亲戚，同为非参数优势估计，但它要把经验固化成可调用的技能，JitRL 没有这层抽象。GAM 是理念呼应，同样冻结权重、把智能移到测试时，但它管的是输入侧往上下文放什么，JitRL 管的是输出侧的动作概率。
