Personal Agent 是今年 Q4 最热闹的 AI 领域：Meta 的 Muse、OpenAI 的 dots、Instinct，以及 Anthropic 新推出的 Claude Duet，让大厂、AI Labs 和创业公司同台竞争。

它也是最像互联网的 AI 命题：如果用户开始把需求交给 agent，那么从用户入口、流量分配，以及交易闭环，都会被被重新组织。

不过，考虑到 Personal Agent 的单用户服务成本远高于传统互联网产品，产品或商业模式角度的也有可能会失效。

今天对 Personal Agent 的想象一定会受限于我们过去的认知和经验。参考 PC 的进化演变，从 Palm、Windows Mobile，直到 iPhone 才找到真正适合大众的移动计算体验。Personal Agent 也才刚刚开始，整个领域同样需要一个“iPhone 时刻”，即找到真正让普通人自然、持续使用的个人智能产品形态。

以下是我们对 Personal Agent 主题 Best Ideas 讨论的观点整理。

⁠

/

⁠

Insight *01*

这一轮 Personal Agent 新在哪里？

　⁠

1.和 Chatbot 比，“更主动、能办事”是 personal agent 的关键进步。过去的交互主要是用户提问、AI 提供信息；但连接 Gmail 等服务、获得用户背景和授权后，agent 开始有机会主动替用户处理事务。

　⁠

2.Personal agent 与 Chatbot 的关系，可能更像推荐与搜索的关系。Personal Agent 对用户的吸引力在于主动性。Chatbot 里很多用户不知道可以让 AI 做什么，也很难把需求表达清楚。如果每次都要用户先提问，使用就会受到限制，但当 Agent 具备 proactive 的能力时就可以有效解决这个问题。

　⁠

3.年初 OpenClaw 的爆火和 personal agent 是一条线的叙事，personal agent 最重要的进步是产品化和云端托管，解决了普通用户搭建、配置和维护的负担，更加“开箱即用”。

　⁠

4.比如 Meta 的 Muse 其实就是把持续运行的云端环境、连接账户与服务的 connector、可重复使用的 skills，以及后台多 agent 协作放进同一个产品。用户可以直接在手机上给 Muse 交办任务，不需要先把这些部件逐一配好。

　⁠

5.Meta AI 产品负责人 Nat Friedman 也明确提到，Muse 的产品设计从 OpenClaw 上得到了不少启发。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh2v5LZ1vlbhmEbwM6qdB2HrCYV7ibGLcyvLicjHeFVceJ1yxeMeARjiaoeOKSoWD1v2JibVxA99Mpbb3wxKbPzUKFr1kZXiaVazzhhA/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1)

　⁠

6.模型进步给 personal agent 带来的产品变化非常重要：模型在长任务执行、工具调用和指令遵循方面的能力进步，让 personal agent 开始变得可用，如果未来百亿、两百亿参数的模型能做好长任务，就可能给 personal agent 带来像 GPT 4o 当年那样的用户增长。

　⁠

7.Grok Bot 和 Muse 不能 head-to-head 地对比：

　⁠

•Grok Bot 更像一人公司（OPC）或美国小微企业的工作助理。它能操作应用、浏览网页和调用工具，替企业主或员工处理具体任务。用户还可以把 Codex 等工具接入 Grok Bot 托管的云电脑，之后只需要统一向 Grok Bot 交办任务，由它调用相应工具执行。

　⁠

•但 personal agent ，尤其是 Muse，很明显对生活场景的优化做得更好。在一些用户的亲身体验中，Muse 处理购物、在 Facebook 上与卖家讨价还价和保险等任务时，能够在 10 分钟内完成，而其他 agent 往往要 20 至 30 分钟。

　⁠

8.随着这两个产品的功能边界不断发生变化，两者能做的事情也有了很多重合，比如 Muse 上个月也推出了企业版，它通过在 Muse App 中加入面向 small business 的连接器和 skills，定位是能读取经营数据、跨软件执行任务的 AI 经营助手。

　⁠

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/QUs3kaltEh2YWrrFHJjyTrqk8nDiaQ0CoIwQHOtWWLpNibTdUibwGNQkauf8hOIAic21icqibgh0jTc374Vm43dTXsp4zQ3Ys3K0xrJnHswFQMNRg/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)

　⁠

9.如果 personal agent 能把语音、跨端使用、主动交互和个人场景优化做好，仍能让产品用起来很不一样。

Insight *02*

产品使用体感

　⁠

10.从用户的直接使用体感来看，大家普遍在重复性、繁杂的信息处理和检索类任务上来使用 personal agent，其中，购物和个人财务类任务是最能感受到 personal agent 产品价值的场景。

　⁠

==11.====“定期补货”或许是 personal agent 目前相对明确的一个场景：每周购买的生鲜杂货相近，目标明确，重复下单又费时间，完全可以交给 agent 来完成。==

　⁠

12.此外，AI 擅长的信息检索和比较也可以外化到购物体验上。比如有用户原本习惯去 Amazon 购买物品，Agent 却帮他找到了此前没考虑过的 Best Buy，最后促成了购买。

　⁠

==13.====个人财务相关：例如报税、保险、产品订阅管理等。这类任务的典型特征是：流程繁琐，但因为关系到真金白银，用户之前不得不花大量时间来处理。并且在这类场景上，因为 personal agent 既能让用户节省时间，还能直接感受到的收益，因此这一场景比普通购物场景有更大的想象空间。==

　⁠

14.基于上述，站在开发者的视角，要判断一项任务是否值得交给 agent，不能只看 agent 执行任务的成本，还要比较它替用户省去多少沟通、办理手续的时间和麻烦。

　⁠

15.前面提到的产品体验主要是针对海外市场，国内 personal agent 产品首先需要面临的是接入问题，生态的封闭、 API 生态不够成熟，让独立 agent 更难获得账户数据，替用户执行后续操作的实现度更是很大挑战。

　⁠

16.作为典型的 To C 应用，Personal agent 的产品角色形象可能也是影响普通人是否愿意尝试 personal agent 的要素之一。Muse 更有亲近感，会让原本不熟悉 AI 的人更愿意尝试。而 Instinct 基于 iMessage 没有明确的角色形象，Grok Bot 和 ChatGPT 的 dots 的形象都偏像素或几何设计。

　⁠

Insight *03*

Personal Agent 需要自己的“iPhone 时刻”

　⁠

17.AI 产品已经积累了庞大的用户群，ChatGPT、Claude、Gemini 等产品去重后估算可能有 6 亿日活，已经是一个相当 meaningful 的数字，而今天的头部产品例如 Facebook 大致在 20 亿 DAU。

　⁠

18.这个趋势最直接体流量分配的改变上：当用户把需求交给 agent，由它跨平台搜索、比较并完成购买，过去受限于个人注意力和使用习惯的选择范围就可能扩大。比如用户原本只习惯在 Amazon 购物，agent 却可能找到 Best Buy 等此前未考虑的渠道。这个变化也可能压缩部分依赖信息不对称赚钱的业务。

　⁠

19.从 Muse 的早期用户规模来看，“Facebook 级别的机会”也是可预期的：估算角度，Muse 上线一个多月后，就有了～300 万 DAU，每名日活用户每天发起 10 次以上 prompt。虽然 Meta 旗下应用的导流贡献了 ～60%—70%，但 Muse 的数据仍旧是 Personal Agent 需求验证的重要信号。

　⁠

20.但 Personal Agent 的现实瓶颈也很明显：

　⁠

•今天用户可能还是要用上 Muse 2-3 周，才能逐渐进入重度使用的状态；

　⁠

•根据 Sensor Tower 的数据，在 9 月、81 个国家的 iOS 与 Android 新安装用户中，Muse 安装后第 1 天的打开率高于 ChatGPT，到第 14 天则低于 ChatGPT；

　⁠

•其中一种可能是普通人没有那么多值得交给 personal agent 来办的事，也就是说，能长期提供邮箱、职业资料、代码仓库等背景、又不断提出高价值任务的人群有多大，仍需要讨论。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh22kHSKSHKicJnN0qjcricGgVM5IHVEQwBcD7suKU23R1QPQDra1k52XYaiasTHpF0NumOIN6Xu4R6veTFYbHNv1L7gGmKtfH7B9c/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=4)

　⁠

==21.====但 Personal Agent 类产品也已经开始在解决帮助用户“发现需求”这件事，以 Muse 为例：==

==⁠==

==•== ==Muse 用 Goals 保存用户长期想完成的目标，再用 ideas 提供新的任务建议，目标是希望用户在一次任务结束后，还能找到下一件值得交办的事。==

　⁠

•有调研估算，目前只有约 10% 的交互由 agent 先发起（agent 主动发起时，多是依据用户的近期计划、到访地点或搜索记录），90% 仍由用户先发起。

　⁠

22.当然，用户展示出来的数据未必反映真实需求。从推荐内容到主动完成实际行动，产品面临的难度更高，因此主动性的实现会是一个循序渐进的过程。

　⁠

==23.====不过，仍有一类声音是质疑当下市场对 Personal Agent 的部分热度是否来自大众对个人助理的想象，而相比之下，企业里的 agent 同事或许比消费级 personal agent 更可能产生万亿美元级公司：==

==⁠==

==•== ==企业有更明确的任务来源；==

==⁠==

==•== ==企业的业务记录、内部沟通信息和流程中的新事项，都能给 agent 提供待处理的事；==

==⁠==

==•== ==团队里只要有少数能提出有价值任务、搭建流程的人，就能带动其他成员使用，而非要求每个人都不断想出新任务。==

　⁠

24.人们往往沿着已有的产品形态想象未来：今天对 Personal AI 的想象，可能像当年尝试把 PC 搬到小屏幕上，再配上键盘和触控笔，却没有直接得到真正适合大众的移动计算体验，直到 iPhone 出现才实现这一目标。这个演进也说明，找到让普通人自然、持续使用 Personal AI 的产品形态的过程可能比预期更漫长。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh1maibgLwpvPNI9ZtyucLqVVQl0T3ibDicWKLe6syFUaAjvAAJGA6OJahibdeWibH5JOc99pjFNvwZvzhuQfcVqW74dVic1j13E9108E/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=5)

　⁠

25.时间窗口长带来的影响，不是对落后者会更宽容，而是让领跑者也非常煎熬：它们需要建设生态、持续留住用户，甚至在亏损中坚持投入，最终迈过拐点。

Insight *04*

产品能力提升靠什么

　⁠

## 模型

　⁠

26.接下来值得关注的是，模型能否继续降低 personal agent 的使用门槛，让它像 coding agent 一样明显变得更好用。

　⁠

27.围绕个人任务设计 benchmark，再根据表现调优模型，可以很大程度上改善 agent 处理这些任务的表现。办公场景中的 AutomationBench 就提供了一种参考：在模拟企业环境中，让 agent 通过 API 完成跨应用任务，再检查要求的操作是否真正生效。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh2DmicjH7y96vKdVjBUwkicibSyC8KDINuC8rz3eEB5b00eno8p4KiaxicT11OzVTJfhic6sSpennxiahLZBlicD4P9UkHIYyzud1ezm0Q/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=6)

左右滑动查看更多图表

　⁠

28.Meta 的 agent 模型 Muse Wonder 就很强调 active memory 和 active focus 能力，分别对应跨对话保留重要上下文、在长任务中持续围绕目标执行。

　⁠

29.Muse 目前还是用搜索等常规工具读取记忆，并在模型推理前按需要提供相关内容。如果这些检索和信息提供的工作已经做好，那么专门训练模型的记忆能力，还能带来什么提升？

　⁠

## Context

　⁠

30.普通用户未必关心背后用了哪个模型，更在意产品用起来怎么样。大家开始更多地讨论产品体验，产品本身的重要性正在上升。

　⁠

31.也有用户认为，长期来看，得到用户个人的信息比使用 SOTA 模型更重要，甚至模型会是 personal agent 里最不重要的一环。

　⁠

•以电脑类比，换 CPU 会改变运行速度和能使用的软件，但只要原有数据和状态还在，用户仍会觉得这是自己的电脑。

　⁠

•因此，相比 coding 工具把主要产物和项目状态留在代码仓库里，personal agent 除了要留下单次任务的结果，还需要长期保存用户资料和任务进度，并有能使用外部服务的账户和身份。

　⁠

32.但 agent 能拿到用户的背景信息，并不等于理解了用户想要什么结果。比如有用户在 Claude Code 与 Codex 之间切换时发现，即便把原有 agent 掌握的背景信息搬过去，新 agent 仍可能不明白用户的真实需求。

　⁠

33.即使 agent 理解了用户想要什么结果，agent 办事时仍要分清哪些动作可以自行完成，哪些必须先问用户。

　⁠

•比如读邮件、起草回复和直接发出邮件，带来的后果是不同的。

　⁠

•写代码可以通过运行和测试检查结果，个人事务往往没有同样明确的检查办法。如果每一步都要用户确认，用户仍得花精力盯着，如果全让 agent 自行处理，agent 又可能发错消息或作出难以撤回的承诺。

　⁠

34.为了让 agent 做好专业任务，还有一种分工设想：由掌握个人身份、记忆、目标和权限的主 agent，按需调用编程、法律、健康或财务等专业 agent。

　⁠

•比如在编程任务中，有开发者用 DeepSeek V4.1 Flash 驱动 Hermes，并在同一台电脑上安装 Codex CLI，在需要写代码或修 bug 时，他就会让 Hermes 先写任务单，再交给 Codex 执行。

　⁠

35.Personal agent 早期重在产品，中期看模型，长期则看生态。

　⁠

## 生态

　⁠

36.国内国外的生态环境差异很大，而这一差异限制了国内和海外在 Personal Agent 产品体验上的差距：

　⁠

•国内的个人信息、支付和生活服务更多集中在超级应用里，独立产品较难读取其中的个人信息。

　⁠

•美国许多服务仍围绕 PC 网页展开，agent 通过浏览器操作网页，已经能提供不错的体验。

　⁠

37.但即便 agent 在技术上能操作网页，平台也可能限制它接入，比如今年 9 月，Amazon 就屏蔽了 Muse，阻止它代用户购物。

　⁠

•一种解释是，平台不愿让新入口截走用户关系和业务利益。因此，如果 agent 服务商与平台能谈妥合作后的利润分配，生态接入的阻力可能减小。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh3iaOD3XxXcWcjG9bYLnBq43wWJwhMXgIn9wB4tp80ibe3ClEj3iaPvVDu7qicBONhQnYKRJrHRtgiawQTibGCIqRVicw0P05rrfxUoVo/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=8)

　⁠

38.除了接入大平台生态，agent 也可以直接连接商家。比如瑞幸已提供 MCP 服务，支持 agent 搜索门店、选品和下单，关键环节仍需用户确认和支付。

　⁠

39.行业也在尝试建立通用的接入协议。Meta、Sierra 正与 Instinct、Shopify、Stripe、Walmart 等公司共同开发 Personal Agent Protocol，让用户决定授予 agent 哪些权限，企业决定允许 agent 执行哪些操作。

　⁠

![图片](https://mmbiz.qpic.cn/mmbiz_png/QUs3kaltEh2uZCkicXL8iakZkZtqWWf2SJ3NmBMSM8yyd5T8frHBfLxaptURWMsfSwzMmyUfWbuibz4icMMKZCyBZvuvibia3cG64Siac1rLkWr6sc/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=9)

　⁠

40.不过，即便开放支付或 agent 互通协议，也不一定能解决所有接入问题。Agent 在实际执行时，仍要处理个人数据接入、账户授权，以及用户设备与云端如何配合执行任务、保护隐私等问题。

　⁠

41.这些生态接入难题也带来一个创业设想：能否由专门的服务商帮助 agent 接入不同平台，并获得平台的数据访问授权？或许大厂和创业团队都可以尝试提供这类服务，但能否做成一门生意，还不确定。

　⁠

Insight *05*

成本测算

　⁠

42.Personal agent 的成本包括模型推理、运行环境和对外身份的配置。在 personal agent 的服务成本上，不同人的估算差异较大。

　⁠

•有从业者估计，Muse 和 Instinct 每名用户每天约需 1 至 5 美元。

　⁠

•参考 Morgan Stanley 估算，如果用户每周用掉 5% 至 10% 的 token 额度，Muse 每月服务一名用户约需 10 至 18 美元，其中 CPU 沙箱成本约为 5 至 8 美元。

　⁠

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/QUs3kaltEh3Hd18RIcXAuhvPcc95ItXbemfxvictfTacsJNKIInEr9nNkNSeDp09yaq5XjxKzsTTCEcaffpeba6evthVdP9ApJQFxq8f8ibUs/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=10)

　⁠

43.OpenClaw 爆火之后，一个曾尝试将 personal agent 产品化的团队，分享了当时搭建和运行产品的成本：

　⁠

•给每个 agent 配备独立计算环境和可靠的网络身份，每名用户每月至少需要约 50 美元（不包含 token）：团队最初试过 Mac Mini，觉得价格高，也难以规模化，但改用带桌面的虚拟机后发现，即使按 AWS 大客户价格，每月仍需 10 至 15 美元。按团队当时的方案，用于注册外部服务的 Gmail 账户每月还需要 14 美元，再加上电话、信用卡等身份配置，固定开支已经不低。

　⁠

•Token 开支随模型型号和用户使用强度变化。团队早期给 personal agent 用的是当时最好的模型，测算发现，重度用户每月仅 token 就可能消耗约 1000 美元。

　⁠

•总的来说，用户正常使用 personal agent 产品时，算上 token 和计算资源，每名用户每月约需 50 至 100 美元，这已是当时的最低量级。

　⁠

44.除了成本，团队还遇到了规模化接入的问题：部分网站限制注册，大量 agent 所需的邮箱、电话和信用卡身份也很难规范配置。因此，增加预算并不一定就能服务更多用户。

　⁠

45.但估算成本时要注意区分使用场景和资源配置情况：

　⁠

•企业场景下，20 人的财务团队可以共用一台虚拟机，80 人的产研团队可以分摊两台或一台高配虚拟机。

　⁠

•虚拟机资源还可以超卖，即分给多台虚拟机的资源总量可以超过物理机器实际拥有的资源，其中 CPU 可超卖的比例高于内存；

　⁠

•此外，工作 agent 可能一天运行十几至二十小时，普通生活助理每天则可能只有十几次请求，因此不应该按照工作 agent 长时间运行的方式估算生活助理成本。

　⁠

46.考虑到近期 personal agent 产品集中出现的一个原因是，更多团队已经能做出接近 SOTA 水平的模型。因此掌握自有模型和算力的厂商，还可以尝试通过蒸馏小模型，进一步控制 agent 的运行成本。

　⁠

47.生态开放可能降低单次任务的执行成本，但更可靠的履约也可能带来更多任务。模型降价后，agent 还可以投入更多推理来发现需求，因此单位成本下降，并不意味着总 token 消耗下降。

　⁠

48.除了当下普遍使用的云端方案，也有人提出，随着本地模型能力和运行效率提升，可以考虑把部分 agent 任务交给用户设备上的本地模型。但这个方案就会带来一个问题，到底哪些可以交给本地模型，哪些仍需调用云端模型？

　⁠

49.模型能在本地运行，对于普通用户来说仍旧存在设备维护成本，因此面向大众的服务可能仍会以云端为主，而数据敏感或有特殊需求的人群则会选择本地方案，两者可能长期并存。

　⁠

50.到 2027-2028 年，技术、供应链和市场供需的变化可能进一步降低本地部署门槛，让本地 agent 设备更容易推广。到那时候，这类设备或许能像企业激光打印机一样，成为可以直接采购使用的标准产品。

　⁠

　⁠

Insight *06*

什么样的收费模式更适合 Personal Agent

　⁠

51.AI Application 和移动互联网相比最大的区别在于边际成本。Personal agent 的单用户服务成本可能比传统互联网高 2-3 个数量级，因此，互联网商业模式有可能会失效。

　⁠

52.订阅制是大多数 Agent 产品，尤其是生产力类产品的收费方式，但 Muse 已经提供了免费服务，因此对于 personal agent 来说，在今天的竞争环境下，短期靠消费级订阅实现增长的难度很大。

　⁠

53.不过，订阅制虽然面临免费产品的竞争，却可能更符合个人助理替用户节省注意力的出发点。

　⁠

54.但愿意花钱节省时间、重视办事结果的用户可能会接受按量收费，或按结果付费、收取分成：

　⁠

•对用户：假设 agent 帮用户节省 1000 美元保险费，那么就可以从节省额中收取费用；

　⁠

•对交易方：可以把 Instinct 这类独立 personal agent 的商业模式设想概括为“AI 携程”，帮用户对接外部服务方、完成服务购买，agent 服务商再从交易中分成。

　⁠

•但也有人对交易分成换取收入表示质疑，因为 ChatGPT 中有明确购物等商业目的的高价值意图只占 ～5%。

## 以 Muse 为例：免费服务怎样回本？

　⁠

55.Muse 免费提供生活助理服务，对普通人很有吸引力，有用户甚至把 Muse 的出现比作当年 Gmail 的推出：普通人原本难以长期负担的个人助理服务，有机会成为日常生活的一部分。

　⁠

==56.====不过，Muse 能否长期提供免费服务，还要看它能找到怎样的收入来源。有观点看好通过 Muse Feed 获得广告收入，因为用户使用生活助理时，可能会更愿意接受广告和商业推荐。相比之下，用户用 ChatGPT、Claude 处理工作时，会很反感回答里插入商业推荐。==

　⁠

57.但如前文所说，如果 Muse 服务一名用户每月至少需要 10 至 20 美元，那么即使 Muse 做到 Meta 其他成熟应用的单用户收入水平，也可能覆盖不了成本。

　⁠

•Meta 2026 年 Q2 财报显示，Meta 旗下应用的 ARPP（每人平均季度收入）为 16.86 美元，折合每月约 5.62 美元，其中包括 Facebook、Instagram 等应用的广告及其他收入。

　⁠

•因此，Muse 或许应该先把每名用户的月服务成本再降一个数量级，降到约 1 至 2 美元，让收入先覆盖成本，再进行模型和产品改进。

Insight *07*

谁有优势：大厂、AI Labs，还是独立团队？

　⁠

## 大厂

　⁠

### Meta & Google

　⁠

59.Meta 和 Google 被看好，首先来自于他们在身份认证、基础模型、用户基数等优势，更为重要的还是二者的算力储备：在 Personal Agent 竞争下，只有拥有充分算力资源厂商才能持续提供免费服务、获取用户。

　⁠

60.公司品牌会影响用户是否愿意连接账户，比如一位 Muse 的使用者就表示，相比 Instinct，他更愿意把账户权限交给 Meta。

　⁠

61.Google 的优势首先来自 Gmail：海外许多正式事务都是通过邮件处理，邮箱既保留历史往来，也可以给 personal agent 不断带来新任务。

　⁠

62.Pixel 和 Android 也让 Google 拥有了设备层入口，能从硬件到软件一体化优化用户体验，而不只依靠与手机厂商的软件合作。

　⁠

63.不过，Google 会投入多少资源做 personal agent，还取决于业务重点和算力分配：

　⁠

•Google 的外部客户、搜索推荐、DeepMind 和云业务都在占用算力，消费级 agent 的优先级较低；

　⁠

•但搜索本来就是 agent 完成任务的一步，因此 personal agent 其实与 Google 搜索主业关系紧密，如果未来算力供给增加，Google 可能会提高 personal agent 的优先级；

　⁠

### Apple

　⁠

64.以 iPhone 为代表的智能手机是真正的大众级个人计算设备，持续承载着用户的日程、位置、沟通和服务记录。因此，Apple 等设备平台在 Personal Agent 竞争中的角色不能被忽视。

　⁠

65.中立的平台角色也是 Apple 的优势：

　⁠

•作为平台方，它可能更容易协调开发者和服务商，让 agent 能够接入更多服务，服务商也可能更愿意合作；

　⁠

•Apple 的封闭生态也让 Apple 更有能力要求开发者按统一规则向 agent 开放服务。

　⁠

•相比之下，Google 自己经营应用和服务，与部分合作方存在竞争，因此合作方可能不愿把用户入口交给它；而 Android 生态又更开放，Google 也更难统一要求开发者配合。

　⁠

66.但 OS 权限是否有不可替代的作用，仍有争论。也有人认为，Apple 和现有手机、设备厂商不会成为 personal agent 最重要的玩家，因为目前还不存在只有拿到 OS 权限才能完成、而云端 agent 做不了的任务。而且，app 只是用户使用 agent 的当前入口。如果未来 agent 能主动替用户办事，用户也不再需要通过某个固定的 app 使用它，那么现有 app 和设备入口的重要性就可能下降。

　⁠

•针对这一观点，有人补充表示，少数身份核验场景仍依赖实体设备：某些验证需要在特定时间、地点通过实体设备完成，有些网站登录则要用前置摄像头扫脸或后置摄像头扫码，这是云端 agent 无法完成的任务。

　⁠

### OpenAI

　⁠

67.OpenAI 和互联网大厂一样拥有庞大的用户基础和前沿模型，虽然现在 dots 的交互体验并不是最好的。

　⁠

## 独立团队

　⁠

68.更看好独立团队的人认为，创业团队做产品的动力来自自己想把这件事做好，大厂可能只是看到商业机会后跟进。在这一派看来，personal agent 的产品形态还会变化，团队需要持续投入、作出产品选择，最初为什么想做这件事就很重要。

　⁠

69.对小团队从哪里切入，也有不同设想。

　⁠

•设想一：专业需求已经能由在垂类工具上加 AI 功能来满足，没有必要再做一个垂直 personal agent。

　⁠

•设想二：personal agent 可以与硬件结合，硬件作为了解用户情况、让用户接触并使用产品的媒介，或许可以在教育、健康等领域提供独特用户体验。

　⁠
