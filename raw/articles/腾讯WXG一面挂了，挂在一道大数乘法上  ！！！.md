面试时间：10.19，微信读书，一面。 结果：挂。

面试官开场说约的会议室里还有人，让我先自我介绍、同时给我道题先做着。我当时还觉得挺人性化，四十分钟后才知道这是提前处刑。

题目是大数乘法。

不是，哥们，ACM 选手都不练这东西了吧。我磨蹭了半个小时，写出来一版只能跑通一部分用例的，还有个进位 bug 没堵住。面试官回来扫了一眼，说了句"行，那我们聊项目"，我那一刻就知道结束了。

## 挂了之后还记得的问题

1. 自我介绍。
2. 手撕：大数乘法（这个先跳过，耻辱柱）。
3. 会不会 C++，用过 C++ 的原子计数吗？（只拿 C++ 写过算法的人，听到这个有点当场去世）
4. 实习：coding agent 的记忆怎么做的。
5. 你们的 agent 和 Claude Code、Codex 有什么区别。
6. 你们怎么对 agent 做评测的。（这是组里另一个实习生的产出，我只能讲个大概）
7. 云 agent 容器迁移或者重启了，上下文怎么办。（同上，简历上根本没写，只是对接过）
8. goal 这里怎么做任务持续推进而不行为漂移。
9. coding agent 接的什么模型。
10. 你觉得在模型能力足够强的前提下，agent 最重要的是什么。
11. 模型能力不够的时候，工程上怎么补。

第 6、7 题我是硬撑的。面试官问得很客气，但那种客气里带着"这明显不是你的活"。

## 复盘

我原来以为手撕挂掉是运气问题，后来想明白了，不是。

大数乘法这种东西，LeetCode 上确实没有，但它考的东西特别朴素：给你一个没有边界说明、没有测试用例、没有标准输入格式的需求，你能不能在脑子里先把它拆成"逆序存、逐位乘、进位、去前导零"这几步。

我练了两百多道题，全都是干净的输入、明确的约束、现成的模板。真到了要自己定义接口的时候，我那套肌肉记忆一点用没有。

所以我现在的判断可能有点反直觉：AI 把业务代码写得越顺，手撕反而越重要。

因为能被 AI 顺顺当当写掉的那部分，正好是"有明确输入输出"的部分。剩下没被写掉的，全是"没人告诉你输入长什么样"的部分。面试官拿一道脏题出来，就是在看你会不会在没有规格说明的地方开工。

这个能力没法靠刷题刷出来，只能靠真的从零写过东西。

至于项目和 agent 那几问，我认了。简历上借了别人的产出撑门面，被问两句就露馅，这个不怪面试官。

那天从会议室出来，我在楼下便利店买了瓶水，坐了一会儿。

技术债是要还的，尤其是简历上借的那种。
